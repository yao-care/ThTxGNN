## Bupropion: จากภาวะซึมเศร้าและการเลิกบุหรี่ สู่โรคสมาธิสั้น (ADHD)
{: .text-alpha }

## สรุปสั้นๆ

Bupropion เดิมใช้รักษาภาวะซึมเศร้าและช่วยเลิกบุหรี่ โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **โรคสมาธิสั้น (Attention Deficit-Hyperactivity Disorder)** ปัจจุบันมี **การทดลองทางคลินิก 6 รายการ** และ **วรรณกรรม 20 ฉบับ** สนับสนุนแนวทางนี้ แต่การทดลองที่ตรงกับตัวยาโดยชัดเจนมีขนาดเล็กหรือเป็นกลุ่มย่อย

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ซึมเศร้า, เลิกบุหรี่ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | โรคสมาธิสั้น (Attention Deficit-Hyperactivity Disorder) |

| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Proceed with Guardrails |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลยา อย่างไรก็ตาม วรรณกรรมที่รวบรวมได้ระบุว่า Bupropion ยับยั้งการดูดกลับของนอร์เอพิเนฟรินและโดพามีน (NDRI) โดยไม่มีฤทธิ์ต่อเซโรโทนิน

ภาวะบกพร่องของระบบแคเทโคลามีน (โดพามีนและนอร์เอพิเนฟริน) เกี่ยวข้องกับโรคสมาธิสั้น ยากระตุ้นอย่างเมทิลเฟนิเดตก็ออกฤทธิ์ผ่านระบบนี้ ดังนั้น Bupropion จึงถูกใช้นอกฉลากเป็นทางเลือกกลุ่มไม่กระตุ้นในผู้ที่ตอบสนองหรือทนต่อยากระตุ้นไม่ได้

ข้อบ่งใช้เดิม (ซึมเศร้า) และโรคสมาธิสั้นเป็นโรคทางจิตเวชที่พบร่วมกันบ่อย และมีกลไกสารสื่อประสาทที่ทับซ้อนกัน จึงสนับสนุนความสมเหตุสมผลของการคาดการณ์

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้ที่พบในกราฟความรู้ของโมเดล** (ไม่ใช่ข้อความจากเอกสารกำกับยา): ลมชัก, ความดันโลหิตสูง, โรคตับและตับแข็ง, โรคไต, โรคอารมณ์สองขั้วระยะแมเนีย, โรคจิตเภทและโรคจิตอื่นๆ, ภาวะติดสารเสพติด/ติดฝิ่น, กล้ามเนื้อหัวใจตายเฉียบพลัน, โรคเบื่ออาหารและบูลิเมีย, โรควิตกกังวล, เนื้องอกระบบประสาทส่วนกลาง
- **ปฏิกิริยาระหว่างยา** (พบทั้งหมด 100 รายการ ตัวอย่างระดับรุนแรง): Fentanyl, Lidocaine, Tramadol, Codeine, Dihydrocodeine, Alfentanil, Methylphenidate, Hydrocortisone, Aldesleukin, Amantadine
- ปฏิกิริยาระดับปานกลางที่พบ เช่น Alprazolam, Ethanol, Nifedipine, Hydrochlorothiazide, Cetirizine, Chlorpheniramine

ข้อห้ามใช้หลายรายการ (เช่น ติดสารเสพติด ความดันโลหิตสูง) ทับซ้อนกับกลุ่มผู้ป่วยสมาธิสั้นที่ศึกษาอยู่ จึงต้องประเมินอย่างระมัดระวัง นอกจากนี้ควรดูคำเตือนและข้อห้ามใช้ฉบับเต็มในเอกสารกำกับยา

**การตัดสินใจ: Proceed with Guardrails**

มีการทดลอง Phase 3 และ Phase 2/3 ที่เสร็จสิ้น รวมถึงการทบทวนของ Cochrane สนับสนุน แต่การทดลองที่ยืนยันว่าใช้ bupropion ได้ชัดเจนมีขนาดเล็กหรือเป็นกลุ่มย่อย และทะเบียนยาในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ตรวจสอบว่ายาที่ใช้ใน NCT00048360 และ NCT00061087 คือ bupropion จริงหรือไม่
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาของ อย. ไทยเพื่อยืนยันคำเตือนและข้อห้ามใช้ (ข้อมูลส่วนนี้ยังขาดอยู่และเป็นอุปสรรคต่อการประเมินความปลอดภัย)
- เติมข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ตรวจสอบสถานะทะเบียนยาในไทย เนื่องจากไม่มีทะเบียนที่ยังใช้งานอยู่
- วางแผนคัดกรองผู้ป่วยที่มีข้อห้ามใช้ โดยเฉพาะลมชัก ความดันโลหิตสูง และภาวะติดสารเสพติด รวมทั้งตรวจสอบปฏิกิริยาระหว่างยา
