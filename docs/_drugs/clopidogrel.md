# Clopidogrel: จากการป้องกันลิ่มเลือดสู่ไมเกรนชนิดมีออร่าจากก้านสมอง (Migraine with Brainstem Aura)

## สรุปสั้นๆ

Clopidogrel เดิมใช้ป้องกันลิ่มเลือด โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ไมเกรนชนิดมีออร่าจากก้านสมอง (Migraine with Brainstem Aura)** ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกที่ลงทะเบียนไว้สำหรับโรคนี้โดยตรง** มีเพียง **วรรณกรรม 16 ฉบับ** ซึ่งส่วนใหญ่ศึกษาไมเกรนชนิดมีออร่าโดยรวม โดยเฉพาะผู้ป่วยที่มีรูรั่วระหว่างหัวใจห้องบน (PFO) ไม่มีฉบับใดศึกษาชนิดก้านสมองโดยเฉพาะ

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ป้องกันลิ่มเลือด |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ไมเกรนชนิดมีออร่าจากก้านสมอง (Migraine with Brainstem Aura) |
| คะแนนการทำนาย TxGNN | 99.44% |
| ระดับหลักฐาน | L4 (หลักฐานเป็นการอนุมานจากไมเกรนชนิดมีออร่า ไม่ได้ศึกษาชนิดก้านสมองโดยตรง) |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกแล้ว (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ข้อมูลที่รวบรวมสำหรับรายงานนี้ไม่มีรายละเอียดกลไกการออกฤทธิ์ของยา ตามความรู้ทั่วไป Clopidogrel เป็นยาต้านตัวรับ P2Y12 ของเกล็ดเลือดแบบไม่ผันกลับ ช่วยลดการกระตุ้นและการจับกลุ่มของเกล็ดเลือด ประสิทธิผลในการป้องกันลิ่มเลือดได้รับการพิสูจน์แล้ว

ในเชิงกลไก การยับยั้งเกล็ดเลือดอาจลดลิ่มเลือดขนาดเล็กที่หลุดผ่านรูรั่วในหัวใจ (paradoxical microemboli) และลดสารออกฤทธิ์ต่อหลอดเลือดจากเกล็ดเลือด เช่น เซโรโทนิน สารเหล่านี้ถูกเสนอว่าเป็นตัวกระตุ้นออร่าในผู้ป่วยที่มีทางลัดเลือดจากขวาไปซ้าย (right-to-left shunt) สอดคล้องกับงานวิจัยหลายชิ้นที่พบว่าอาการไมเกรนดีขึ้นเมื่อใช้ Clopidogrel ในผู้ป่วย PFO หรือหลังการปิดรูรั่วในหัวใจ

อย่างไรก็ตาม ยังไม่มีหลักฐานเฉพาะชนิดก้านสมอง การสนับสนุนทั้งหมดอนุมานจากไมเกรนชนิดมีออร่า จึงควรมองว่านี่คือ "คำถามวิจัย" ไม่ใช่ข้อบ่งใช้ที่พร้อมนำไปใช้ทางคลินิก

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้องกับไมเกรนชนิดมีออร่าจากก้านสมองโดยตรง

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้จากฐานความรู้ทางชีวการแพทย์ (ไม่ใช่ข้อความจากเอกสารกำกับยา)**: ตับวายเฉียบพลัน, ตับอักเสบ, โรคการแข็งตัวของเลือดผิดปกติ, การบาดเจ็บ, ภาวะเกล็ดเลือดต่ำชนิด purpura, แผลในกระเพาะอาหารที่ยังเป็นอยู่, เลือดออกในกะโหลกศีรษะ
- **ปฏิกิริยาระหว่างยา**: พบรายการทั้งหมด 100 รายการ รายการระดับรุนแรง (Major) ที่สำคัญ ได้แก่ Omeprazole, Esomeprazole, Rabeprazole, Pioglitazone, Loperamide และ Repaglinide ส่วนระดับปานกลาง เช่น Acetylsalicylic acid, Morphine, Clarithromycin, Cimetidine และ Bupropion
- **ข้อควรระวังเพิ่มเติม**: ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของไทยยังไม่มี กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา นอกจากนี้ ยากลุ่มต้านเกล็ดเลือดเพิ่มความเสี่ยงเลือดออก ซึ่งต้องชั่งน้ำหนักกับประโยชน์ในผู้ป่วยไมเกรนที่ไม่ได้มีโรคหลอดเลือดอยู่เดิม

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ไม่มีการทดลองทางคลินิกหรือหลักฐานเฉพาะไมเกรนชนิดก้านสมอง หลักฐานที่มีมาจากไมเกรนชนิดมีออร่าที่เกี่ยวข้องกับ PFO ทะเบียนยาในไทยก็ถูกยกเลิกแล้ว
- ไมเกรนทั่วไป (Migraine disorder) มีหลักฐานแข็งแรงกว่า (ระดับ L2) เช่น การทดลอง CANOA (Phase 4, RCT) และ COMPETE (Phase 2) จึงน่าพิจารณาเป็นแนวทางหลักของการวิจัยต่อ โดยมีมาตรการกำกับดูแลความปลอดภัย (Proceed with Guardrails) แต่ผลต้องจำกัดอยู่ที่ผู้ป่วย PFO หรือหลังปิดรูรั่วหัวใจ

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียด (MOA)
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- หลักฐานเฉพาะชนิดก้านสมอง เช่น รายงานผู้ป่วยหรือการศึกษานำร่อง และการยืนยันว่าผู้ป่วยมีทางลัดเลือดขวาไปซ้าย
- สถานะทะเบียนยาและแหล่งจัดหายาในไทย เนื่องจากทะเบียนเดิมถูกยกเลิก
- แผนติดตามความเสี่ยงเลือดออกและปฏิกิริยาระหว่างยา โดยเฉพาะกลุ่ม PPI
