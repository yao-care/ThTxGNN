## Gabapentin: จากปวดประสาทและโรคลมชักสู่สิว (Acne)
{: .text-alpha }

## สรุปสั้นๆ

Gabapentin เดิมใช้รักษา**อาการปวดจากเส้นประสาทและโรคลมชัก** โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **สิว (Acne)** แต่ตอนนี้ยังไม่พบ**การทดลองทางคลินิก**หรือ**วรรณกรรม**ที่สนับสนุนข้อบ่งใช้นี้เลย หลักฐานมีเพียงคะแนนจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ปวดประสาท, โรคลมชัก |
| ข้อบ่งใช้ใหม่ที่ทำนาย | สิว (Acne) |
| คะแนนการทำนาย TxGNN | 98.46% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ✗ มีเฉพาะทะเบียนที่ถูกยกเลิก |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

Gabapentin จับกับหน่วยย่อย alpha2delta ของช่องแคลเซียมที่ไวต่อแรงดันไฟฟ้า ทำให้การหลั่งสารสื่อประสาทกระตุ้นลดลง กลไกนี้อธิบายการใช้ในโรคลมชักและอาการปวดจากเส้นประสาทได้ดี ข้อมูลกลไกการออกฤทธิ์จากฐานข้อมูลยาโดยตรงยังไม่ครบถ้วน

ตามข้อมูลที่ทราบ **ยังไม่มีความเชื่อมโยงเชิงกลไกที่ชัดเจนระหว่างกลไกนี้กับพยาธิสรีรวิทยาของสิว** เช่น การอักเสบ การสร้างไขมัน หรือเชื้อ *C. acnes* คะแนนจากโมเดลจึงเป็นเพียงสัญญาณเชิงสถิติจากโครงข่ายความรู้ และไม่ควรตีความว่ายามีประสิทธิผลต่อสิว

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้ตามฐานความรู้ของโมเดล** (ไม่ใช่ข้อความจากเอกสารกำกับยา): โรคกังวล (anxiety disorder), โรคประสาท (neurotic disorder), โรคซึมเศร้าเรื้อรังระดับอ่อน (dysthymic disorder), โรคไต (kidney disease), ภาวะหนองในท่อไต (pyoureter)
- **ปฏิกิริยาระหว่างยา**: พบรายการปฏิกิริยาระหว่างยาทั้งหมด 100 รายการ รายการหลักที่ควรระวัง:
  - **ระดับรุนแรง (Major)**: Morphine, Morphine (liposomal)
  - **ระดับปานกลาง (Moderate)**: Dronabinol, Nabilone, Metoclopramide, Opium, Sibutramine
  - ระดับเล็กน้อย (Minor) เช่น Cimetidine และยาลดกรดกลุ่มแมกนีเซียม/อะลูมิเนียม

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของไทยยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้สิวมีเพียงคะแนนจากโมเดล (ระดับหลักฐาน L5) ไม่มีการทดลองทางคลินิก ไม่มีวรรณกรรม และไม่มีเหตุผลเชิงกลไกรองรับ
- ทะเบียนยาในไทยถูกยกเลิกแล้ว และยังไม่มีข้อมูลเตือนและข้อห้ามใช้จากเอกสารกำกับยา

**หากต้องการดำเนินการต่อต้อง:**
- ทบทวนวรรณกรรมและทำการศึกษาก่อนคลินิก เพื่อหาความเชื่อมโยงเชิงกลไกระหว่างช่องแคลเซียม alpha2delta กับพยาธิกำเนิดของสิว
- ดึงข้อมูลกลไกการออกฤทธิ์จาก DrugBank ให้ครบ
- ดาวน์โหลดเอกสารกำกับยาของ อย. ไทย เพื่อประเมินคำเตือนและข้อห้ามใช้
- ตรวจสอบสถานะการขึ้นทะเบียนใหม่ เพราะทะเบียนเดิมถูกยกเลิก
- พิจารณาข้อบ่งใช้อื่นในรายการทำนายที่มีหลักฐานมากกว่า เช่น **กลุ่มอาการปวดพังผืดกล้ามเนื้อ (Myofascial pain syndrome)** ซึ่งมีการทดลองทางคลินิกและวรรณกรรมสนับสนุนบางส่วน (ระดับหลักฐาน L2, Proceed with Guardrails) ควรประเมินแยกต่างหาก
## ข้อจำกัดความรับผิดชอบ

จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
