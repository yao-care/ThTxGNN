## Tramadol: จากอาการปวดปานกลางถึงรุนแรง สู่ acromesomelic dysplasia ชนิด Hunter-Thompson
{: .text-alpha }

## สรุปสั้นๆ

Tramadol เดิมใช้บรรเทาอาการปวดปานกลางถึงรุนแรง โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **Acromesomelic Dysplasia ชนิด Hunter-Thompson** แต่ปัจจุบัน **ไม่มีการทดลองทางคลินิกและไม่มีวรรณกรรมที่เกี่ยวข้อง** สนับสนุนการคาดการณ์นี้ จึงยังเป็นเพียงผลจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | บรรเทาปวดปานกลางถึงรุนแรง |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Acromesomelic Dysplasia, Hunter-Thompson type |
| คะแนนการทำนาย TxGNN | 0.9999 |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Tramadol เป็นยาที่กระตุ้นตัวรับโอปิออยด์ชนิดมิว (mu-opioid) ร่วมกับยับยั้งการดูดกลับของเซโรโทนินและนอร์เอพิเนฟริน เพื่อระงับปวด

เมื่อพิจารณาโรคที่ทำนาย ภาวะนี้เป็นความผิดปกติทางพันธุกรรมของกระดูก (เกี่ยวข้องกับยีน CDMP1/GDF5) ซึ่งกลไกของ Tramadol ไม่ได้แก้ที่สาเหตุทางพันธุกรรมนี้ **จึงยังไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจน** อย่างมากที่สุดยาอาจบรรเทาอาการปวดได้เท่านั้น และคะแนนสูงของ TxGNN ไม่มีหลักฐานจริงรองรับ

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- การคาดการณ์มาจากโมเดลเพียงอย่างเดียว ไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุน และไม่พบความเชื่อมโยงเชิงกลไกกับโรคนี้
- ใบอนุญาตในไทยถูกยกเลิกแล้ว และยังขาดข้อมูลความปลอดภัยจากเอกสารกำกับยา

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- คำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- หลักฐานก่อนคลินิกหรือการศึกษากลไกที่เชื่อมยากับโรคนี้
- ตรวจสอบสถานะใบอนุญาตในประเทศไทยว่ามีผลิตภัณฑ์ที่ยังวางจำหน่ายหรือไม่

**หมายเหตุ:** โรคที่ทำนายอันดับถัดไป (เช่น brachyolmia, pseudoachondroplasia, juvenile idiopathic arthritis) ก็อยู่ที่ระดับ L5 และคำแนะนำ Hold เช่นกัน วรรณกรรมเพียงฉบับเดียวที่พบ (ใน juvenile idiopathic arthritis) เป็นเรื่องของ ketoprofen ไม่ใช่ Tramadol จึงไม่ใช่หลักฐานของยานี้
