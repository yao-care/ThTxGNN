# Metoclopramide: จากอาการคลื่นไส้อาเจียนสู่แผลในกระเพาะอาหาร

## สรุปสั้นๆ

Metoclopramide เดิมใช้บรรเทาอาการคลื่นไส้อาเจียน โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **แผลในกระเพาะอาหาร (Gastric Ulcer)** ปัจจุบันมี **การทดลองทางคลินิก 1 รายการ** และ **วรรณกรรม 20 ฉบับ** แต่เป็นหลักฐานทางอ้อมเป็นส่วนใหญ่ ยานี้ไม่ได้รักษาแผลโดยตรง

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | คลื่นไส้อาเจียน |
| ข้อบ่งใช้ใหม่ที่ทำนาย | แผลในกระเพาะอาหาร (Gastric Ulcer) |
| คะแนนการทำนาย TxGNN | 99.93% |
| ระดับหลักฐาน | L4 |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกแล้วทั้งหมด (ไม่มีทะเบียนที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมมา ตามข้อมูลที่ทราบ Metoclopramide เป็นยาต้านตัวรับโดพามีน D2 และกระตุ้นตัวรับ 5-HT4 ช่วยให้กระเพาะอาหารบีบตัวและระบายอาหารเร็วขึ้น รวมถึงลดอาการคลื่นไส้อาเจียน

ความเชื่อมโยงกับแผลในกระเพาะอาหารอยู่ที่ระดับอาการและการช่วยในหัตถการ เช่น อาจช่วยให้เห็นภาพชัดขึ้นตอนส่องกล้องในผู้ป่วยเลือดออกทางเดินอาหารส่วนบน แต่ **ไม่ได้รักษาตัวแผลเอง** การรักษามาตรฐานยังคือการลดกรดและกำจัดเชื้อ H. pylori

นอกจากนี้ ข้อมูลกราฟความรู้ชี้ว่ายามีข้อห้ามใช้ที่เกี่ยวข้อง เช่น แผลเปื่อยที่ยังเป็นอยู่ จึงต้องใช้ด้วยความระมัดระวังอย่างมาก

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้ที่พบจากกราฟความรู้ (ไม่ใช่ข้อความจากเอกสารกำกับยา):** ความดันโลหิตสูง, โรคลมชัก, โรคกังวล/โรคประสาท, พอร์ฟิเรีย, ตับแข็ง, ไตทำงานบกพร่อง, เนื้องอกต่อมหมวกไตชนิด pheochromocytoma, แผลเปื่อยที่ยังเป็นอยู่, กลุ่มอาการ neuroleptic malignant, อาการเคลื่อนไหวผิดปกติแบบ tardive dyskinesia, โรคพาร์kinson และ torsion dystonia
- **ปฏิกิริยาระหว่างยา (พบ 100 รายการ ตัวอย่างที่สำคัญ):**
  - ระดับรุนแรง (Major): tramadol, amisulpride
  - ระดับปานกลาง (Moderate): fentanyl, codeine, alprazolam, amitriptyline, amantadine, ethanol และยาแก้แพ้บางชนิด เช่น chlorpheniramine, cetirizine
- ควรดูคำเตือนและข้อห้ามใช้ฉบับเต็มในเอกสารกำกับยา เนื่องจากข้อมูลส่วนนี้ยังไม่ครบ

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- หลักฐานอยู่ที่ระดับ L4 เป็นการศึกษาเชิงกลไกและทางอ้อมเป็นหลัก การทดลองเดียวที่พบศึกษาการช่วยส่องกล้อง ไม่ใช่การรักษาแผล
- ใบอนุญาตในไทยถูกยกเลิกทั้งหมด และข้อมูลคำเตือนจากเอกสารกำกับยายังขาด จึงยังประเมินความปลอดภัยไม่ได้

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจเอกสารกำกับยาของ อย. ไทย เพื่อยืนยันคำเตือนและข้อห้ามใช้
- เก็บข้อมูลกลไกการออกฤทธิ์จาก DrugBank เพิ่มเติม
- กำหนดคำถามวิจัยให้ชัด เช่น ใช้ช่วยส่องกล้องในเลือดออกทางเดินอาหารส่วนบน ซึ่งมีผลการศึกษาแบบ RCT ใหม่ๆ (เช่น PMID 38059896 และ 42259699) แต่ผลยังขัดแย้งกัน แทนการรักษาแผลโดยตรง
- ตรวจสอบสถานะการขึ้นทะเบียนใหม่ในไทย และวางมาตรการป้องกันด้านความปลอดภัย เพราะมีข้อห้ามใช้ในภาวะเลือดออกและการอุดตันทางเดินอาหาร
