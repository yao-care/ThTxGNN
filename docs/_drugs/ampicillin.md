# Ampicillin: จากโรคติดเชื้อแบคทีเรียสู่โรคกล่องเสียงอักเสบ (Laryngitis)

## สรุปสั้นๆ

Ampicillin เป็นยาปฏิชีวนะกลุ่มเพนิซิลลิน เดิมใช้รักษาโรคติดเชื้อแบคทีเรียทั่วไป โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **โรคกล่องเสียงอักเสบ (Laryngitis)** โดยเฉพาะกรณีที่เกิดจากแบคทีเรีย เช่น ฝาปิดกล่องเสียงอักเสบ (epiglottitis) ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกที่ลงทะเบียนไว้** และมี **วรรณกรรม 20 ฉบับ** ซึ่งส่วนใหญ่เป็นหลักฐานทางอ้อม (รายงานผู้ป่วย การทบทวน และข้อมูลจุลชีววิทยา)

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | โรคติดเชื้อแบคทีเรีย |
| ข้อบ่งใช้ใหม่ที่ทำนาย | กล่องเสียงอักเสบ (Laryngitis) |
| คะแนนการทำนาย TxGNN | 99.97% |
| ระดับหลักฐาน | L4 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกแล้ว (ไม่มีใบอนุญาตที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกทั้งหมด) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Ampicillin เป็นยาปฏิชีวนะกลุ่มเบต้า-แลคแทมที่ยับยั้งการสร้างผนังเซลล์แบคทีเรีย ประสิทธิผลในการรักษาโรคติดเชื้อแบคทีเรียได้รับการพิสูจน์แล้ว และในเชิงกลไกอาจใช้ได้กับการติดเชื้อแบคทีเรียที่กล่องเสียงและบริเวณใกล้เคียง

วรรณกรรมที่พบเกี่ยวข้องกับฝาปิดกล่องเสียงอักเสบเฉียบพลันที่เกิดจาก *Haemophilus influenzae* ชนิด b ฝีที่กล่องเสียง และการติดเชื้อลึกบริเวณคอ ซึ่งในอดีตมีการใช้ Ampicillin เป็นส่วนหนึ่งของการรักษา แต่หลักฐานทั้งหมดเป็นทางอ้อมและไม่ได้เปรียบเทียบประสิทธิผลโดยตรง

ข้อควรระวังสำคัญคือกล่องเสียงอักเสบส่วนใหญ่เกิดจากไวรัส ซึ่งยาปฏิชีวนะไม่ได้ผล นอกจากนี้เชื้อ *H. influenzae* บางสายพันธุ์ดื้อต่อ Ampicillin จึงต้องจำกัดการใช้เฉพาะกรณีที่มีหลักฐานการติดเชื้อแบคทีเรีย

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้ที่พบจากฐานความรู้เชิงกราฟ (ไม่ใช่ข้อความจากเอกสารกำกับยา)**: โรคไต, ภาวะการทำงานของไตบกพร่อง, โรคทางโลหิตวิทยา, แผลในกระเพาะอาหาร, ลำไส้ใหญ่อักเสบจาก *Clostridium difficile*, ลำไส้เน่าในทารกแรกเกิด, โรคโมโนนิวคลีโอสิสติดเชื้อ (infectious mononucleosis), กลุ่มอาการติดเชื้อ Epstein-Barr ไวรัสเรื้อรัง, ไตอักเสบจากกรดยูริกเฉียบพลัน และภาวะหนองในท่อไต
- **ปฏิกิริยาระหว่างยา**: พบข้อมูลทั้งหมด 61 รายการ ที่ระดับปานกลาง ได้แก่ doxycycline, minocycline, tetracycline, kanamycin, balsalazide, lansoprazole, dexlansoprazole และ picosulfuric acid ส่วน clarithromycin อยู่ในระดับเล็กน้อย
- โปรดดูคำเตือนและข้อห้ามใช้อย่างเป็นทางการในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- หลักฐานมีเพียงระดับ L4 ซึ่งเป็นข้อมูลทางอ้อม ไม่มีการทดลองทางคลินิก และกล่องเสียงอักเสบส่วนใหญ่เกิดจากไวรัส นอกจากนี้ใบอนุญาตในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์ (MOA) จาก DrugBank
- เอกสารกำกับยาของ อย. ไทย เพื่อตรวจสอบคำเตือนและข้อห้ามใช้ (ช่องว่างข้อมูลระดับ Blocking)
- ข้อมูลการดื้อยาในประเทศไทยของเชื้อที่เป็นสาเหตุหลัก เช่น *H. influenzae*
- การศึกษาเชิงเปรียบเทียบในกลุ่มที่ยืนยันการติดเชื้อแบคทีเรียที่กล่องเสียง
- ตรวจสอบสถานะใบอนุญาตหรือทางเลือกยาในกลุ่มเดียวกันที่ยังจำหน่ายอยู่ในไทย
