## Spironolactone: ยาต้านมิเนอรัลคอร์ติคอยด์รีเซพเตอร์และต้านแอนโดรเจน → ภาวะขนบางบนหนังศีรษะชนิดซิมเพล็กซ์ (hypotrichosis simplex of the scalp)
{: .text-alpha }

## สรุปสั้นๆ

Spironolactone เป็นยาที่ออกฤทธิ์ต้านมิเนอรัลคอร์ติคอยด์รีเซพเตอร์และมีฤทธิ์ต้านแอนโดรเจน โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **ภาวะขนบางบนหนังศีรษะชนิดซิมเพล็กซ์ (hypotrichosis simplex of the scalp)** ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรม** ที่สนับสนุน จึงเป็นเพียงการทำนายจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ไม่มีบันทึกในข้อมูลท้องถิ่น |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ภาวะขนบางบนหนังศีรษะชนิดซิมเพล็กซ์ (hypotrichosis simplex of the scalp) |
| คะแนนการทำนาย TxGNN | 0.9926 |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | อยู่ในบัญชียาหลักแห่งชาติ (1 จาก 1 รายการ) – ข้อมูลนี้ไม่รวมสถานะทะเบียนตำรับยาของ อย. |
| จำนวนรายการในบัญชียาหลักแห่งชาติ | 1 รายการ (ยังมีผล 1) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ แต่ตามที่ทราบกัน spironolactone เป็นยาต้านมิเนอรัลคอร์ติคอยด์รีเซพเตอร์ที่มีฤทธิ์ต้านแอนโดรเจนด้วย จึงอาจส่งผลต่อรูขุมขนได้

อย่างไรก็ตาม ยังไม่มีหลักฐานทางคลินิกหรือวรรณกรรมที่สนับสนุนการใช้ในภาวะขนบางชนิดถ่ายทอดทางพันธุกรรมนี้ ความเชื่อมโยงเชิงกลไกจึงยังเป็นเพียงข้อสันนิษฐาน และต้องมีการศึกษาเพิ่มเติมก่อนสรุปใดๆ

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: จากการสืบค้นพบปฏิกิริยาระหว่างยารวม 100 รายการ ตัวอย่างที่ควรระวัง
  - ระดับรุนแรง (Major): loperamide
  - ระดับปานกลาง: hydrocortisone, dexamethasone, betamethasone, triamcinolone, budesonide, metformin, bupropion, morphine, ยากลุ่ม SGLT2 (canagliflozin, dapagliflozin, empagliflozin, ertugliflozin), exenatide, bisacodyl, castor oil, dronabinol
  - ระดับเล็กน้อย: doxycycline, aspirin, fidaxomicin

กรุณาดูข้อมูลคำเตือนและข้อห้ามใช้ในเอกสารกำกับยาเพิ่มเติม

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- การทำนายนี้มาจากโมเดลเพียงอย่างเดียว ไม่มีการทดลองทางคลินิกหรือวรรณกรรมที่ศึกษาภาวะนี้โดยตรง (ระดับหลักฐาน L5)

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดของยา
- การทบทวนวรรณกรรมและการศึกษาก่อนคลินิกเกี่ยวกับผลของยาต่อรูขุมขน
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- การประเมินความเหมาะสมของรูปแบบยาและทางให้ยากับภาวะบนหนังศีรษะ
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
