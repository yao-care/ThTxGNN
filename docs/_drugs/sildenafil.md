# Sildenafil: จากภาวะการแข็งตัวขององคชาตสู่ภาวะขนดกแต่กำเนิดชนิด Ambras (Ambras type hypertrichosis universalis congenita)

## สรุปสั้นๆ

Sildenafil เดิมใช้รักษาปัญหาการแข็งตัวขององคชาต โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ภาวะขนดกแต่กำเนิดชนิด Ambras (Ambras type hypertrichosis universalis congenita)** ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและยังไม่มีวรรณกรรมที่เกี่ยวข้องโดยตรง** การทำนายนี้จึงมาจากโมเดลเพียงอย่างเดียว

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามความรู้ทั่วไป Sildenafil เป็นยายับยั้งเอนไซม์ PDE5 ทำให้ระดับ cGMP เพิ่มขึ้นและหลอดเลือดขยายตัว ซึ่งเป็นพื้นฐานของการรักษาภาวะแข็งตัวขององคชาต

อย่างไรก็ตาม ยังไม่พบความเชื่อมโยงที่ชัดเจนระหว่างกลไกนี้กับพื้นฐานทางพันธุกรรมของกลุ่มอาการ Ambras การทำนายนี้จึงมาจาก TxGNN เท่านั้น แม้คะแนนจะสูง แต่ยังไม่มีหลักฐานทางคลินิกหรือวรรณกรรมรองรับ ควรมองเป็นสมมติฐานเบื้องต้น ไม่ใช่ข้อสรุป

**ข้อสังเกตเพิ่มเติม:** ในรายการที่ TxGNN ทำนาย มีข้อบ่งใช้อื่นที่มีหลักฐานอยู่บ้าง คือ **ผมร่วงทางพันธุกรรม (genetic alopecia)** ซึ่งมีงานวิจัยปี 2018 รายงานผลของ sildenafil ต่อการเจริญเติบโตของเส้นผม (ระดับหลักฐาน L4 ข้อมูลเบื้องต้น) แต่มีคะแนน TxGNN ต่ำกว่า (75.03%) และอยู่นอกขอบเขตของรายงานฉบับนี้

## ข้อพิจารณาด้านความปลอดภัย

คำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่พร้อมใช้งาน กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

**ภาวะที่ฐานความรู้ (knowledge graph) ระบุว่ามีความสัมพันธ์เชิงข้อห้ามใช้** (ไม่ใช่ข้อความจากเอกสารกำกับยา ควรยืนยันกับเอกสารกำกับยาอีกครั้ง):
- **หัวใจและหลอดเลือด:** หัวใจขาดเลือดเฉียบพลัน, กล้ามเนื้อหัวใจตาย, ลิ่มเลือดหลอดเลือดหัวใจ, ลิ้นหัวใจเอออร์ติกตีบและโรคลิ้นหัวใจเอออร์ติก, กล้ามเนื้อหัวใจหนาตัว (รวมชนิดครอบครัว), ภาวะความดันโลหิตต่ำ
- **สมองและหลอดเลือดสมอง:** โรคหลอดเลือดสมอง, สมองขาดเลือด/สมองตาย
- **เลือด:** โรคโลหิตจางซิกเคิลเซลล์, ฮีโมโกลบินผิดปกติ, ภาวะฮีโมโกลบินของทารกในครรภ์คงอยู่, พลาสมาเซลล์มัยอีโลมา, มะเร็งเม็ดเลือดขาว
- **ตับ:** ตับวาย
- **อวัยวะเพศ:** ภาวะองคชาตแข็งค้าง (priapism), โรค Peyronie และภาวะที่เกี่ยวข้อง
- **ตาและหู:** โรคเส้นประสาทตาขาดเลือดส่วนหน้า, การสูญเสียการได้ยิน
- **อื่นๆ:** ความผิดปกติของการเคลื่อนไหวหลอดอาหาร, โรคหลอดเลือดดำในปอดอุดตัน

**ปฏิกิริยาระหว่างยา:** ตรวจพบรายการที่อาจเกิดปฏิกิริยาระหว่างยา 100 รายการ ตัวอย่างหลักที่พบ:
- **ระดับรุนแรง (Major):** Clarithromycin
- **ระดับปานกลาง (Moderate):** Aprepitant, Morphine, Dexamethasone, Cimetidine, Miconazole, Clotrimazole, Canagliflozin, Dapagliflozin, Empagliflozin, Ertugliflozin, Papaverine, Opium และอื่นๆ

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- การทำนายนี้อาศัยโมเดล TxGNN เพียงอย่างเดียว ไม่มีการทดลองทางคลินิกและวรรณกรรมสนับสนุน และไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจน
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังขาดอยู่ ทั้งที่เป็นข้อมูลจำเป็นก่อนผ่านการคัดกรองความปลอดภัย และใบอนุญาตของยาในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจากเว็บไซต์ อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้ที่เป็นทางการ
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ค้นหาหลักฐานก่อนคลินิกหรือรายงานผู้ป่วยที่เกี่ยวข้องกับภาวะขนดกแต่กำเนิดชนิด Ambras
- ทบทวนปฏิกิริยาระหว่างยาและข้อห้ามใช้จากฐานความรู้ให้ครบถ้วน
- ตรวจสอบสถานะใบอนุญาตในประเทศไทย เนื่องจากไม่มียาที่ขึ้นทะเบียนที่ยังใช้ได้
- พิจารณาศึกษาข้อบ่งใช้ผมร่วงทางพันธุกรรมแยกต่างหาก เพราะมีสัญญาณหลักฐานเบื้องต้นมากกว่า
