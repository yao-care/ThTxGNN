## Naproxen: จากการบรรเทาปวดและต้านการอักเสบสู่กลุ่มอาการ Brachydactyly-Syndactyly
{: .text-alpha }

## สรุปสั้นๆ

Naproxen เป็นยากลุ่ม NSAIDs ซึ่งเดิมใช้บรรเทาปวดและต้านการอักเสบ
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **กลุ่มอาการ Brachydactyly-Syndactyly (brachydactyly-syndactyly syndrome)** ซึ่งเป็นความผิดปกติของนิ้วมือนิ้วเท้าแต่กำเนิด
อย่างไรก็ตาม **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมสนับสนุน** การทำนายนี้มาจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | บรรเทาปวด, ต้านการอักเสบ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | กลุ่มอาการ Brachydactyly-Syndactyly (brachydactyly-syndactyly syndrome) |
| คะแนนการทำนาย TxGNN | 99.35% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ยกเลิกทะเบียนแล้วทั้งหมด (ไม่มีทะเบียนที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Naproxen เป็นตัวยับยั้งเอนไซม์ COX-1 และ COX-2 แบบไม่เลือกจำเพาะ ทำให้การสร้างพรอสตาแกลนดินลดลง จึงออกฤทธิ์บรรเทาปวดและต้านการอักเสบ

ยังไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจนระหว่างการยับยั้ง COX กับความผิดปกติของแขนขาแต่กำเนิดชนิดนี้ คะแนนที่สูง (99.35%) เป็นเพียงผลทำนายของโมเดล ไม่มีการศึกษาทางคลินิกหรือวรรณกรรมรองรับ จึงไม่ควรตีความว่าเป็นหลักฐานของประสิทธิผล

ข้อบ่งใช้ที่ทำนายอันดับถัดมาก็อยู่ในสถานการณ์เดียวกัน คือเป็นโรคพัฒนาการ/พันธุกรรมที่หายาก ได้แก่ colobomatous microphthalmia-rhizomelic dysplasia syndrome (99.22%), acromesomelic dysplasia ชนิด Hunter-Thompson (99.17%) และ brachyolmia-amelogenesis imperfecta syndrome (99.06%) ทั้งหมดไม่มีหลักฐานสนับสนุนและมีระดับ L5 เช่นกัน

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ |
|---------|------|------|-----------|

## ข้อพิจารณาด้านความปลอดภัย

ข้อมูลจากเอกสารกำกับยาไม่พร้อมใช้งาน กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

ข้อมูลที่มีจากฐานความรู้ของโมเดล (ไม่ใช่ข้อความจากเอกสารกำกับยา) ระบุโรคที่มีความเกี่ยวข้องกับข้อห้ามใช้ ได้แก่
- **หัวใจและหลอดเลือด**: ความดันโลหิตสูง, หัวใจล้มเหลวเรื้อรัง, โรคหลอดเลือดหัวใจ, กล้ามเนื้อหัวใจตายเฉียบพลัน, โรคหลอดเลือดสมอง/สมองขาดเลือด
- **ตับและไต**: ตับวาย, โรคตับ, โรคไต, โรคถุงน้ำดี
- **เลือด**: โรคเลือดออกผิดปกติ/การแข็งตัวของเลือดผิดปกติ, โลหิตจาง, ฮีโมโกลบินผิดปกติ
- **เมตาบอลิก**: เบาหวาน, ภาวะเลือดเป็นกรดจากเบาหวาน (DKA), โรคอ้วน, โรคกระดูกพรุน
- **อื่นๆ**: โรคลมชัก, ต่อมลูกหมากโต, การใช้สารเสพติด

**ปฏิกิริยาระหว่างยา**: พบรายงาน 100 รายการ ตัวอย่างที่ระดับปานกลาง (Moderate) ได้แก่
- ยาลดกรด: famotidine, ranitidine, cimetidine, rabeprazole, dexlansoprazole
- คอร์ติโคสเตียรอยด์: hydrocortisone, dexamethasone, betamethasone, triamcinolone, budesonide
- ยาเบาหวาน: metformin, chlorpropamide
- ยากลุ่ม salicylate/5-ASA: acetylsalicylic acid, mesalazine, balsalazide
- อื่นๆ: aprepitant, potassium citrate, potassium bicarbonate, picosulfuric acid, polyethylene glycol

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
มีเพียงคะแนนทำนายจากโมเดล (L5) โดยไม่มีการทดลองทางคลินิก วรรณกรรม หรือความเชื่อมโยงเชิงกลไกที่สมเหตุสมผล นอกจากนี้ทะเบียนยาในไทยถูกยกเลิกแล้ว และยังขาดข้อมูลข้อห้ามใช้จากเอกสารกำกับยา

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียด (MOA) และการวิเคราะห์ความเชื่อมโยงเชิงกลไกกับโรคเป้าหมาย
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของไทย
- หลักฐานก่อนคลินิกหรือรายงานทางคลินิกที่เกี่ยวข้องกับโรคเป้าหมาย
- การประเมินความเข้ากันได้ของช่องทางให้ยา (ปัจจุบันมีเฉพาะยาเม็ดรับประทาน) และสถานะการขึ้นทะเบียนใหม่ หากจะนำมาใช้จริง
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
