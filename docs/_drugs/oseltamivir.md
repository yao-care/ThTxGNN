# Oseltamivir: จากไข้หวัดใหญ่ สู่ pyelonephritis (กรวยไตอักเสบ)

## สรุปสั้นๆ

Oseltamivir เป็นยาต้านไวรัสที่เดิมใช้รักษาไข้หวัดใหญ่ โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **กรวยไตอักเสบ (Pyelonephritis)** แต่ปัจจุบัน **ยังไม่มีการทดลองทางคลินิก** และมี **วรรณกรรมเพียง 1 ฉบับ** (บทความทบทวนเรื่องไข้หวัดใหญ่ในหญิงตั้งครรภ์ ซึ่งไม่ได้ศึกษาข้อบ่งใช้นี้โดยตรง) จึงถือว่าการทำนายนี้ยังไม่มีหลักฐานสนับสนุน

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ไข้หวัดใหญ่ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | กรวยไตอักเสบ (Pyelonephritis) |
| คะแนนการทำนาย TxGNN | 97.85% |

| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมไว้ ตามความรู้ทั่วไป Oseltamivir เป็นยายับยั้งเอนไซม์ neuraminidase ของไวรัสไข้หวัดใหญ่ ประสิทธิผลในการรักษาไข้หวัดใหญ่ได้รับการพิสูจน์แล้ว

อย่างไรก็ตาม กรวยไตอักเสบเกิดจากการติดเชื้อแบคทีเรียในทางเดินปัสสาวะ ส่วน Oseltamivir ไม่มีฤทธิ์ต้านแบคทีเรียที่ก่อโรคเหล่านี้ จึงไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจน คะแนนทำนายที่สูงจึงควรตีความอย่างระมัดระวัง เพราะเป็นผลจากโมเดลเท่านั้น

**ข้อบ่งใช้อื่นที่โมเดลทำนาย** (เพื่อเปรียบเทียบ): ข้อบ่งใช้ที่มีหลักฐานมากกว่ากรวยไตอักเสบ คืออันดับ 8 **ปอดอักเสบ** (คะแนน 92.14%, ระดับหลักฐาน L3 มีการทดลองทางคลินิก 15 รายการ ส่วนใหญ่เป็นการศึกษาในโรค COVID-19 ที่ใช้ Oseltamivir เป็นยาเปรียบเทียบหรือยาพื้นฐาน จึงยังไม่พิสูจน์ประโยชน์ในปอดอักเสบที่ไม่ใช่ไข้หวัดใหญ่) และอันดับ 9 **ปอดอักเสบจากเชื้อสเตรปโตคอคคัส** (คะแนน 90.46%, L3 ยาอาจลดการติดเชื้อแบคทีเรียแทรกซ้อนหลังไข้หวัดใหญ่โดยทางอ้อม หลักฐานส่วนใหญ่เป็นการศึกษาเชิงสังเกตและในสัตว์ทดลอง) ทั้งสองข้อมีเหตุผลเชิงกลไกที่เข้าใจได้มากกว่า แต่ยังไม่ใช่ข้อบ่งใช้อันดับแรกของโมเดล

## ข้อพิจารณาด้านความปลอดภัย

- **โรคที่ฐานความรู้ระบุว่าเป็นข้อห้ามใช้**: เพ้อสับสนเฉียบพลัน (delirium) ข้อมูลนี้มาจากความสัมพันธ์ในฐานความรู้ ไม่ได้มาจากเอกสารกำกับยา
- **ปฏิกิริยาระหว่างยา**: พบรายการที่เกี่ยวข้อง 66 รายการ ตัวอย่างยาที่พบ ได้แก่ pantoprazole, vancomycin, prednisone, simvastatin, rosuvastatin, clarithromycin, morphine, metformin, omeprazole และ ondansetron ทั้งนี้ยังไม่มีการจัดระดับความรุนแรงของรายการเหล่านี้

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- การทำนายกรวยไตอักเสบอยู่ที่ระดับหลักฐาน L5 ไม่มีการทดลองทางคลินิก ไม่มีกลไกที่รองรับ และยาตัวนี้ไม่มีฤทธิ์ต้านแบคทีเรียที่ก่อโรค นอกจากนี้ใบอนุญาตในไทยถูกยกเลิกแล้ว และข้อมูลความปลอดภัยจากเอกสารกำกับยายังขาดอยู่

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์ที่ครบถ้วนจาก DrugBank
- คำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย (จำเป็นก่อนผ่านการคัดกรองความปลอดภัย)
- พิจารณาข้อบ่งใช้ที่มีเหตุผลเชิงกลไกมากกว่า เช่น ปอดอักเสบหรือปอดอักเสบแทรกซ้อนหลังไข้หวัดใหญ่ แล้วประเมินแยกต่างหาก
- ตรวจสอบสถานะทะเบียนยาในไทย เนื่องจากปัจจุบันไม่มีใบอนุญาตที่ใช้งานได้
