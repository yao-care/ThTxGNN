## Lansoprazole: ยากลุ่มยับยั้งการหลั่งกรด → ภาวะลำไส้เล็กส่วนต้นอุดตัน (duodenal obstruction)
{: .text-alpha }

## สรุปสั้นๆ

Lansoprazole เป็นยาที่ใช้ลดการหลั่งกรดในกระเพาะอาหาร โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **ภาวะลำไส้เล็กส่วนต้นอุดตัน (duodenal obstruction)** อย่างไรก็ตาม ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและยังไม่มีวรรณกรรม** ที่สนับสนุนแนวทางนี้ จึงเป็นเพียงการทำนายจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ไม่มีบันทึกในข้อมูลท้องถิ่น |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ภาวะลำไส้เล็กส่วนต้นอุดตัน (duodenal obstruction) |

| จำนวนทะเบียนตำรับยา | 22 รายการ (ยังมีผล 6) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดของ Lansoprazole ตามข้อมูลที่ทราบ ยานี้เป็นยาลดการหลั่งกรดชนิดรับประทาน (รูปแบบยาเม็ด) ที่ใช้กับโรคในทางเดินอาหารส่วนบน

จากข้อมูลที่รวบรวมไว้สำหรับรายงานนี้ ยังไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจน เพราะการลดกรดไม่สามารถแก้ภาวะอุดตันเชิงกลได้ และการทำนายนี้ไม่มีหลักฐานทางคลินิกหรือวรรณกรรมรองรับ จึงควรมองว่าเป็นเพียงสัญญาณจากโมเดล ไม่ใช่ข้อสรุปเชิงการรักษา

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: ข้อมูลที่รวบรวมพบรายการปฏิกิริยาระหว่างยา 100 รายการ โดยรายการหลักที่ควรระวัง ได้แก่
  - ระดับรุนแรง (Major): Acalabrutinib, Atazanavir
  - ระดับปานกลาง (Moderate): เช่น Hydrochlorothiazide, Amphotericin B, Amikacin, Ampicillin, Fenofibrate, Atorvastatin, Apalutamide, Aprepitant, Bosutinib, Brigatinib, Bromocriptine
  - ระดับเล็กน้อย (Minor): เช่น Acetylsalicylic acid, Axitinib, Brivaracetam, Cyanocobalamin

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบถ้วน กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- การทำนายนี้ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับ และไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจน เพราะยาลดกรดไม่ช่วยแก้ภาวะอุดตันเชิงกล

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียด (MOA)
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- หลักฐานจากการศึกษาที่ศึกษาภาวะลำไส้เล็กส่วนต้นอุดตันโดยตรง
- การประเมินความเข้ากันได้ของช่องทางการให้ยา เนื่องจากยามีเฉพาะรูปแบบรับประทาน
