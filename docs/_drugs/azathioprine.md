## Azathioprine: ยากดภูมิคุ้มกันกลุ่มต้านเมตาบอไลต์พิวริน → กลุ่มอาการตาแหว่งร่วมกับตาเล็กและกระดูกแขนขาส่วนต้นสั้น (colobomatous microphthalmia-rhizomelic dysplasia syndrome)
{: .text-alpha }

## สรุปสั้นๆ

Azathioprine เป็นยากดภูมิคุ้มกันชนิดรับประทาน โมเดล TxGNN คาดการณ์ว่ายานี้อาจเกี่ยวข้องกับ **กลุ่มอาการตาแหว่งร่วมกับตาเล็กและกระดูกแขนขาส่วนต้นสั้น (colobomatous microphthalmia-rhizomelic dysplasia syndrome)** แต่ตอนนี้ **ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรมที่ศึกษาโรคนี้โดยตรง** การคาดการณ์จึงอาศัยคะแนนจากโมเดลเพียงอย่างเดียว

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ตอนนี้ยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดของยานี้ในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามความรู้ทั่วไป Azathioprine เป็นยากดภูมิคุ้มกันที่รบกวนการสังเคราะห์พิวรีนในเซลล์เม็ดเลือดขาวลิมโฟไซต์ที่กำลังแบ่งตัว

โรคที่ทำนายนี้เป็นความผิดปกติแต่กำเนิดของดวงตาและโครงกระดูก ไม่พบกลไกที่อาศัยระบบภูมิคุ้มกันซึ่งยากดภูมิคุ้มกันจะเข้าไปแก้ได้ ผลการประเมินกลไกจึงสรุปว่าไม่มีความเชื่อมโยงที่สมเหตุสมผล และคะแนนจากโมเดลเป็นข้อสนับสนุนเพียงอย่างเดียว คะแนนที่สูงจึงไม่ควรตีความว่ามีประโยชน์ทางคลินิกจริง

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: การตรวจสอบเสร็จสมบูรณ์ พบรายการทั้งหมด 100 รายการ รายการหลักที่ระบุระดับไว้มีดังนี้

| ยาที่มีปฏิกิริยา | ระดับ |
|------|------|
| Mesalazine | ปานกลาง |
| Balsalazide | ปานกลาง |
| Olsalazine | ปานกลาง |
| Sulfasalazine | ไม่มีบันทึกในข้อมูลท้องถิ่น |
| Zinc acetate, Zinc gluconate, Zinc sulfate | เล็กน้อย |

ยาอื่นในรายการที่ตรวจพบ (เช่น Aspirin, Metformin, Omeprazole, Pantoprazole) ยังไม่ระบุระดับความรุนแรง

ข้อมูลคำเตือนและข้อห้ามใช้ยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ไม่มีการทดลองทางคลินิกหรือวรรณกรรมที่ศึกษาโรคนี้โดยตรง และไม่พบกลไกที่เชื่อมยากดภูมิคุ้มกันกับโรคความผิดปกติแต่กำเนิดนี้ หลักฐานจึงอยู่ที่ระดับ L5

**หากต้องการดำเนินการต่อต้อง:**
- หลักฐานก่อนคลินิกหรือกลไกที่แสดงว่า azathioprine เกี่ยวข้องกับพยาธิกำเนิดของโรคนี้
- ข้อมูลกลไกการออกฤทธิ์ของยาที่ครบถ้วน
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาฉบับล่าสุด เพื่อประเมินความปลอดภัยก่อนพิจารณาต่อ
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
