# Diphenhydramine: จากอาการแพ้และนอนไม่หลับ สู่โรคจมูกอักเสบ (Rhinitis)

## สรุปสั้นๆ

Diphenhydramine เป็นยาต้านฮีสตามีนรุ่นแรก เดิมใช้รักษาอาการแพ้และนอนไม่หลับ
โมเดล TxGNN จัดอันดับข้อบ่งใช้ใหม่ที่มีหลักฐานมากที่สุดคือ **โรคจมูกอักเสบ (Rhinitis)** ซึ่งส่วนใหญ่เป็นการใช้ที่เป็นที่ยอมรับอยู่แล้ว
ปัจจุบันมี **การทดลองทางคลินิก 5 รายการ** และ **วรรณกรรม 19 ฉบับ** ที่เกี่ยวข้อง แต่ในจำนวนนี้มีเพียง 1 การทดลองที่ทดสอบประสิทธิผลโดยตรง (Phase 4)

> หมายเหตุ: ข้อบ่งใช้ที่ทำนายอันดับ 1 ของโมเดลคือ rosacea conjunctivitis แต่ไม่มีหลักฐานสนับสนุนเลย (L5, Hold) รายงานนี้จึงเน้นโรคจมูกอักเสบ (อันดับ 2) ซึ่งมีหลักฐานมากที่สุด และสรุปข้อบ่งใช้อื่นไว้ท้ายรายงาน

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | อาการแพ้, นอนไม่หลับ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | โรคจมูกอักเสบ (Rhinitis) |
| คะแนนการทำนาย TxGNN | 98.35% |
| ระดับหลักฐาน | L2 (ตามการประเมินของข้อมูลที่รวบรวมสำหรับรายงานนี้) |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกแล้ว (ไม่มีใบอนุญาตที่ใช้งานได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิก 1 รายการ) |
| คำแนะนำในการตัดสินใจ | Proceed with Guardrails |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Diphenhydramine เป็นยาต้านตัวรับฮีสตามีน H1 รุ่นแรก ซึ่งมีฤทธิ์ต้านโคลิเนอร์จิกและทำให้ง่วงด้วย

การปิดกั้นตัวรับ H1 ช่วยลดอาการจาม น้ำมูกไหล และคัดจมูกที่เกิดจากฮีสตามีนในโรคจมูกอักเสบจากภูมิแพ้ ซึ่งสอดคล้องกับข้อบ่งใช้เดิมคืออาการแพ้ ทั้งสองเป็นภาวะที่ฮีสตามีนมีบทบาทสำคัญ จึงถือว่าเป็นการใช้ที่ใกล้เคียงกับข้อบ่งใช้เดิมมาก และเป็นการใช้ที่เป็นที่ยอมรับอยู่แล้วในทางคลินิก

อย่างไรก็ตาม เอกสารแนวปฏิบัติ (เช่น CSACI 2019) แนะนำให้ใช้ยาต้านฮีสตามีนรุ่นใหม่เป็นลำดับแรก เพราะ Diphenhydramine ทำให้ง่วงและกระทบการรู้คิด

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: พบ 100 รายการ ตัวอย่างที่ระดับรุนแรง (Major) ได้แก่ Potassium citrate และ Eliglustat ส่วนระดับปานกลาง (Moderate) ได้แก่ ยาต้านโคลิเนอร์จิก (Atropine, Hyoscyamine, Glycopyrronium, Dicyclomine), ยากลุ่มโอปิออยด์ (Morphine, Loperamide), Bupropion และ Metoclopramide
- **ข้อควรระวังจากวรรณกรรม**: ง่วงซึม การรู้คิดลดลง ปากแห้ง เวียนศีรษะ และฤทธิ์ต้านโคลิเนอร์จิกที่อาจรบกวนการระบายเหงื่อในที่ร้อน

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยา ยังไม่ได้ข้อมูลมา กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Proceed with Guardrails** (สำหรับโรคจมูกอักเสบ)

**เหตุผล:**
- มีการทดลอง Phase 4 ขนาดใหญ่ (1,021 ราย) และ RCT หลายฉบับที่ยืนยันประสิทธิผลในโรคจมูกอักเสบภูมิแพ้ แต่ยานี้ทำให้ง่วงและมีฤทธิ์ต้านโคลิเนอร์จิก จึงต้องมีมาตรการป้องกัน
- ใบอนุญาตในไทยถูกยกเลิกทั้งหมด จึงยังไม่มีผลิตภัณฑ์ที่วางจำหน่ายได้ตามกฎหมาย

**หากต้องการดำเนินการต่อต้อง:**
- ตรวจสอบสถานะการขึ้นทะเบียนใหม่หรือเหตุผลที่ยกเลิกใบอนุญาต 1A 69/67 กับ อย. ไทย
- ดาวน์โหลดและตรวจเอกสารกำกับยาเพื่อให้ได้คำเตือนและข้อห้ามใช้ (ข้อมูลส่วนนี้ขาดอยู่และถือเป็นข้อมูลที่ขัดขวางการคัดกรองความปลอดภัย)
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- วางแนวทางลดความเสี่ยงจากอาการง่วงและฤทธิ์ต้านโคลิเนอร์จิก โดยเฉพาะในผู้สูงอายุ เด็ก และผู้ที่ใช้ยาต้านโคลิเนอร์จิกหรือโอปิออยด์ร่วม
- พิจารณาเปรียบเทียบกับยาต้านฮีสตามีนรุ่นใหม่ซึ่งเป็นยาลำดับแรกตามแนวปฏิบัติ
