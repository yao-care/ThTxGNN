# Allopurinol: จากเก๊าต์และกรดยูริกในเลือดสูง สู่พอร์ฟิเรียของตับ (Hepatic Porphyria)

## สรุปสั้นๆ

Allopurinol เดิมใช้รักษาโรคเก๊าต์และภาวะกรดยูริกในเลือดสูง โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **พอร์ฟิเรียของตับ (Hepatic Porphyria)** ปัจจุบัน **ยังไม่มีการทดลองทางคลินิก** และมี **วรรณกรรมที่เกี่ยวข้องเพียง 2 ฉบับ** ซึ่งเป็นบทความสมมติฐานและการศึกษาในสัตว์ทดลอง จึงจัดว่าหลักฐานยังอยู่ในขั้นเริ่มต้นมาก

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | เก๊าต์, กรดยูริกในเลือดสูง |
| ข้อบ่งใช้ใหม่ที่ทำนาย | พอร์ฟิเรียของตับ (Hepatic Porphyria) |

| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Allopurinol เป็นยากลุ่มยับยั้งเอนไซม์แซนทีนออกซิเดส (xanthine oxidase) ซึ่งลดการสร้างกรดยูริก ประสิทธิผลในการรักษาเก๊าต์ได้รับการพิสูจน์แล้ว

ในเชิงกลไก มีการตั้งสมมติฐานว่ายานี้อาจเกี่ยวข้องกับเมแทบอลิซึมของฮีมในตับและการหมุนเวียนของไซโทโครม P450 ซึ่งอาจส่งผลต่อเอนไซม์ 5-aminolevulinate synthase (5-ALAS) ที่เป็นเอนไซม์ควบคุมอัตราการสร้างฮีม อย่างไรก็ตาม **ความเชื่อมโยงนี้เป็นเพียงสมมติฐาน ยังไม่มีการพิสูจน์ทางคลินิก**

วรรณกรรมที่พบไม่ได้ศึกษา Allopurinol โดยตรง ฉบับหนึ่งเป็นบทความสมมติฐานเรื่องการกำหนดเป้าหมายเมแทบอลิซึมของ 5-ALAS ในพอร์ฟิเรียเฉียบพลัน อีกฉบับเป็นการศึกษาในหนูเกี่ยวกับ carbamazepine ที่ทำให้พอร์ฟิเรียกำเริบ จึงสนับสนุนได้เพียงบริบททางชีวเคมีทั่วไปเท่านั้น

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้จากฐานความรู้ TxGNN (ไม่ใช่ข้อความจากเอกสารกำกับยา)**: โรคตับ, โรคถุงน้ำดี, ภาวะการทำงานของไตบกพร่อง, หลอดเลือดอักเสบจากภาวะภูมิไวเกิน, หลอดเลือดอักเสบที่ผิวหนังชนิด leukocytoclastic, หลอดเลือดอักเสบที่ผิวหนังจากภูมิแพ้, โรคแอนติบอดีต่อเยื่อฐานไตฝอย (anti-GBM)
- **ปฏิกิริยาระหว่างยา**: พบรายการที่ตรวจพบรวม 100 รายการ รายการหลักระดับปานกลาง (Moderate) ได้แก่ อะลูมิเนียมไฮดรอกไซด์, attapulgite, kaolin, magaldrate และ sucralfate (กลุ่มยาลดกรดและยาเคลือบกระเพาะ) ส่วนระดับเล็กน้อย (Minor) ได้แก่ amoxicillin และ chlorpropamide นอกจากนี้ยังมีรายการที่ยังไม่ระบุระดับ เช่น metformin, omeprazole, pantoprazole, morphine และ doxycycline

ข้อควรสังเกตเป็นพิเศษ: ผู้ป่วยพอร์ฟิเรียของตับมีโรคตับเป็นพื้นฐาน ซึ่งตรงกับข้อห้ามใช้ที่พบในฐานความรู้ จึงต้องประเมินอย่างระมัดระวังมาก ส่วนคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ยังไม่มีการทดลองทางคลินิก หลักฐานมีเพียงการทำนายจากโมเดลและวรรณกรรมเชิงสมมติฐานกับการศึกษาในสัตว์ที่ไม่ได้ศึกษา Allopurinol โดยตรง
- ทะเบียนยาในไทยถูกยกเลิกทั้งหมด และมีข้อห้ามใช้ในโรคตับจากฐานความรู้ ซึ่งเกี่ยวข้องกับกลุ่มโรคเป้าหมายโดยตรง

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดของ Allopurinol ต่อเมแทบอลิซึมของฮีมและ 5-ALAS
- การศึกษาก่อนคลินิกที่ทดสอบ Allopurinol ในแบบจำลองพอร์ฟิเรียโดยตรง
- เอกสารกำกับยาของ อย. ไทยเพื่อตรวจสอบคำเตือนและข้อห้ามใช้ (ข้อมูลที่ขาดอยู่และจำเป็นก่อนประเมินความปลอดภัย)
- ตรวจสอบสถานะทะเบียนยาและผู้ผลิตที่มีทะเบียนใช้งานอยู่ในประเทศไทย
- พิจารณาข้อบ่งใช้อื่นที่ทำนายไว้ แต่ส่วนใหญ่ยังไม่มีหลักฐานสนับสนุน (ระดับ L5)
## ข้อจำกัดความรับผิดชอบ

จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
