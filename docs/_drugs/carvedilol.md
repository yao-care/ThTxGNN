# Carvedilol: จากความดันโลหิตสูงและหัวใจล้มเหลว สู่ความดันโลหิตสูงรุนแรงจากหลอดเลือดแดงไต (Malignant Renovascular Hypertension)

## สรุปสั้นๆ

Carvedilol เป็นยาปิดกั้นเบต้าที่มีฤทธิ์ปิดกั้นแอลฟา-1 และขยายหลอดเลือดร่วมด้วย เดิมใช้รักษาความดันโลหิตสูงและหัวใจล้มเหลว โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ความดันโลหิตสูงรุนแรงจากหลอดเลือดแดงไต (Malignant Renovascular Hypertension)** อย่างไรก็ตาม ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมสนับสนุนข้อบ่งใช้นี้โดยตรง** หลักฐานจึงมาจากการทำนายของโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ความดันโลหิตสูง, หัวใจล้มเหลว |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ความดันโลหิตสูงรุนแรงจากหลอดเลือดแดงไต (Malignant Renovascular Hypertension) |
| คะแนนการทำนาย TxGNN | 99.55% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีใบอนุญาตที่ยังมีผลบังคับใช้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Carvedilol เป็นยาปิดกั้นเบต้าแบบไม่เลือกจำเพาะ มีฤทธิ์ปิดกั้นแอลฟา-1 และขยายหลอดเลือด ประสิทธิผลในการรักษาความดันโลหิตสูงทั่วไปได้รับการยอมรับแล้ว

ในเชิงกลไก การปิดกั้นทั้งเบต้าและแอลฟา-1 อาจช่วยลดความดันโลหิตในภาวะความดันสูงรุนแรง และอาจลดการบาดเจ็บของหลอดเลือดไตที่ตามมาได้ ข้อสรุปนี้เป็นการอนุมานจากกลุ่มยาเท่านั้น ยังไม่มีข้อมูลทางคลินิกหรือวรรณกรรมสำหรับข้อบ่งใช้นี้

ควรทราบว่าคะแนนการทำนายสูงเท่ากันของข้อบ่งใช้อันดับ 2 (ความดันโลหิตสูงรุนแรงที่ทำลายไต) บ่งชี้ว่าทั้งสองเป็นโรคในกลุ่มใกล้เคียงกัน และยังไม่มีหลักฐานแยกยืนยันได้

## ข้อพิจารณาด้านความปลอดภัย

**ข้อห้ามใช้/โรคที่ควรระวัง (จากฐานความรู้เชิงโครงข่าย ไม่ใช่ข้อความจากเอกสารกำกับยา):**
- โรคตับวาย
- โรคระบบทางเดินหายใจ: หอบหืด (รวมชนิดภูมิแพ้และชนิดแท้), หลอดลมอักเสบ, ถุงลมโป่งพอง, โรคหลอดลม
- เบาหวานและภาวะกรดคีโตนจากเบาหวาน
- ความดันโลหิตต่ำ
- โรคหลอดเลือดส่วนปลาย (รวมอาการปวดขาเป็นพักๆ)
- ภาวะหัวใจห้องบนล่างบล็อก, กลุ่มอาการไซนัสอ่อนแรง (sick sinus syndrome)
- Prinzmetal angina
- ภาวะแพ้รุนแรง (anaphylaxis)
- กลุ่มอาการม่านตาหย่อน (intraoperative floppy iris syndrome)

**ปฏิกิริยาระหว่างยา:** พบข้อมูลรวม 100 รายการ รายการสำคัญได้แก่
- ระดับรุนแรง (Major): Epinephrine
- ระดับปานกลาง (Moderate): คอร์ติโคสเตียรอยด์ (Hydrocortisone, Dexamethasone, Betamethasone, Triamcinolone, Budesonide), Bupropion, Morphine, Atropine, Hyoscyamine, Lorcaserin, Canagliflozin, Acetohexamide และเกลือแคลเซียมบางชนิด
- ระดับเล็กน้อย (Minor): Acetylsalicylic acid, Aluminum hydroxide, Attapulgite

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทยยังไม่ครบถ้วน กรุณาดูเอกสารกำกับยาประกอบ

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล (L5) ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับ และใบอนุญาตเดียวของยาในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ค้นหาและรวบรวมหลักฐานทางคลินิกหรือก่อนคลินิกเกี่ยวกับ Carvedilol ในความดันโลหิตสูงรุนแรงจากหลอดเลือดแดงไต
- เติมข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจาก อย. ไทย เพื่อประเมินคำเตือนและข้อห้ามใช้
- ตรวจสอบสถานะทะเบียนตำรับยาในไทย เนื่องจากปัจจุบันไม่มีใบอนุญาตที่ยังมีผล
- พิจารณาข้อบ่งใช้อื่นที่มีหลักฐานมากกว่า เช่น โรคหัวใจจากปอดเรื้อรัง (L3, มีการศึกษาในผู้ป่วยหัวใจล้มเหลวที่มี COPD ร่วม) หรือความดันปอดสูงจากโรคปอด/ภาวะขาดออกซิเจน และโรคหลอดเลือดสมอง (L4, หลักฐานก่อนคลินิก)
