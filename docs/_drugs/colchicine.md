# Colchicine: จากเก๊าต์เฉียบพลันสู่มาลาเรียชนิด Plasmodium falciparum

## สรุปสั้นๆ

Colchicine เดิมได้รับอนุมัติในประเทศไทยสำหรับรักษา **เก๊าต์เฉียบพลัน**
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **มาลาเรียชนิด Plasmodium falciparum** แต่หลักฐานมีเพียงการศึกษาในห้องปฏิบัติการ 2 ฉบับ และไม่มีการทดลองทางคลินิก
ข้อบ่งใช้ใหม่อันดับ 2 คือ **ไข้เมดิเตอร์เรเนียนในครอบครัว (FMF)** ซึ่งมีวรรณกรรมสนับสนุนมากกว่า (ระดับ L3) และเป็นตัวเลือกที่น่าสนใจกว่าในเชิงปฏิบัติ

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | เก๊าต์เฉียบพลัน |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Plasmodium falciparum malaria (มาลาเรียชนิดฟัลซิปารัม) |
| คะแนนการทำนาย TxGNN | 99.60% |
| ระดับหลักฐาน | L4 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีใบอนุญาตที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดของยาในข้อมูลที่รวบรวมสำหรับรายงานนี้ แต่ตามความรู้ทางเภสัชวิทยา Colchicine จับกับทูบูลินและรบกวนการทำงานของไมโครทูบูล

เชื้อมาลาเรียต้องอาศัยไมโครทูบูลในการแบ่งตัวและเคลื่อนที่ จึงมีเหตุผลเชิงทฤษฎีว่าการรบกวนไมโครทูบูลอาจกระทบเชื้อได้ หลักฐานที่มีเป็นการศึกษาในห้องปฏิบัติการเท่านั้น เช่น การแสดงออกของยีน pfmdr1 ในเซลล์สัตว์เลี้ยงลูกด้วยนมที่ทำให้ความไวต่อยาเปลี่ยนไป และการศึกษาการรบกวนไมโครทูบูลในเชื้อ P. falciparum

อย่างไรก็ตาม ยานี้มีช่วงการรักษาที่แคบ (narrow therapeutic index) ซึ่งจำกัดความเป็นไปได้ในการใช้เป็นยาต้านมาลาเรียอย่างมาก

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## ความเป็นพิษต่อเซลล์

| รายการ | เนื้อหา |
|------|------|
| การจำแนกความเป็นพิษต่อเซลล์ | ยาที่ออกฤทธิ์ยับยั้งไมโครทูบูล/ต้านการแบ่งเซลล์ (antimitotic) ไม่ใช่ยาเคมีบำบัดโดยตรง |
| ความเสี่ยงต่อการกดไขกระดูก | ควรระวัง (ข้อมูลความสัมพันธ์ระบุภาวะเม็ดเลือดขาวต่ำ นิวโทรฟิลต่ำ เกล็ดเลือดต่ำ และไขกระดูกฝ่อ) |
| รายการที่ต้องติดตาม | CBC การทำงานของตับและไต |
| การป้องกันในการจัดการ | กรุณาดูคำเตือนและข้อควรระวังในเอกสารกำกับยา |

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้/ภาวะที่ควรระวัง (จากกราฟความรู้ ไม่ใช่ข้อความในเอกสารกำกับยา):** ตับวาย โรคทางโลหิตวิทยา เกล็ดเลือดต่ำ เม็ดเลือดขาวต่ำ/นิวโทรฟิลต่ำ/แกรนูโลไซต์ต่ำ ภาวะไขกระดูกฝ่อ (aplastic anemia) แผลในกระเพาะอาหาร โรคกล้ามเนื้อและภาวะกล้ามเนื้อสลายตัว (rhabdomyolysis) โรคท้องร่วง และไตทำงานบกพร่อง
- **ปฏิกิริยาระหว่างยา:** พบ 100 รายการ ตัวอย่างระดับรุนแรง (Major) ได้แก่ clarithromycin, cobicistat, aprepitant, rolapitant, eliglustat, deferiprone, rosuvastatin และ simvastatin ส่วนระดับปานกลาง เช่น cimetidine, metronidazole, tinidazole, miconazole, chloroquine, ticagrelor และ disulfiram ซึ่งสะท้อนความเกี่ยวข้องกับ CYP3A4/P-gp

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold** (สำหรับข้อบ่งใช้มาลาเรีย)

**เหตุผล:**
- มีเพียงหลักฐานในห้องปฏิบัติการ ไม่มีการทดลองทางคลินิก และช่วงการรักษาของยาแคบ ประกอบกับยามีความเสี่ยงต่อระบบเลือดและมี DDI จำนวนมาก
- ใบอนุญาตในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย (ปัจจุบันขาดข้อมูล และเป็นอุปสรรคต่อการคัดกรองความปลอดภัย)
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- การศึกษาก่อนคลินิกที่แสดงฤทธิ์ต้านเชื้อที่ความเข้มข้นซึ่งปลอดภัยในมนุษย์
- พิจารณาข้อบ่งใช้ FMF (อันดับ 2, L3, Proceed with Guardrails) เป็นลำดับแรก โดยมีมาตรการกำกับดูแลด้านการทำงานของไตและตับ ปฏิกิริยาระหว่างยา CYP3A4/P-gp และขีดจำกัดขนาดยา รวมถึงต้องขอยื่นทะเบียนตำรับยาใหม่ เนื่องจากใบอนุญาตเดิมถูกยกเลิก
## ข้อจำกัดความรับผิดชอบ

จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
