# Amlodipine: จากความดันโลหิตสูงและโรคหลอดเลือดหัวใจ สู่ภาวะสมองก้านสมองขาดเลือด (Brain Stem Infarction)

## สรุปสั้นๆ

Amlodipine เดิมใช้รักษาความดันโลหิตสูงและโรคหลอดเลือดหัวใจ โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ภาวะสมองก้านสมองขาดเลือด (Brain Stem Infarction)** แต่ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมที่สนับสนุนโดยตรง** การคาดการณ์นี้จึงอาศัยผลจากโมเดลเพียงอย่างเดียว

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ความดันโลหิตสูง, โรคหลอดเลือดหัวใจ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ภาวะสมองก้านสมองขาดเลือด (Brain Stem Infarction) |
| คะแนนการทำนาย TxGNN | 99.94% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ยังใช้งานได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมไว้สำหรับรายงานนี้ ตามข้อมูลที่ทราบ Amlodipine เป็นยาปิดกั้นแคลเซียมชนิด L-type ที่ลดความดันโลหิตด้วยการขยายหลอดเลือด ประสิทธิผลในการรักษาความดันโลหิตสูงได้รับการพิสูจน์แล้ว และในเชิงกลไกอาจให้ผลต่อหลอดเลือดหรือปกป้องเซลล์ประสาทได้

อย่างไรก็ตาม ความเชื่อมโยงกับภาวะสมองก้านสมองขาดเลือดยังเป็นเพียงสมมติฐาน ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับ ความเหมือนกับข้อบ่งใช้เดิมยังอยู่ระหว่างการประเมิน

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

ข้อมูลจากเอกสารกำกับยาของ อย. ไทยยังไม่ครบ จึงควรตรวจสอบเอกสารกำกับยาก่อนใช้งานจริง

- **โรคหรือภาวะที่ฐานความรู้ของโมเดลระบุว่าอาจเป็นข้อห้าม** (มาจากกราฟความรู้ ไม่ใช่ข้อความในฉลากยา): ตับวายและโรคตับ, โรคไต, ตับอ่อนอักเสบ, โรคถุงน้ำดี, ภาวะต่อมไทรอยด์ทำงานต่ำ, ภาวะแองจิโออีดีมา (angioedema) หลายชนิด, โรคลูปัสเอริทีมาโทซัส (SLE), โรคกล้ามเนื้อ, อัมพาตเป็นพักๆ ตามพันธุกรรม, ภาวะขาดโพแทสเซียม, เบาหวานและภาวะคีโตเอซิโดซิสจากเบาหวาน, ภาวะเม็ดเลือดขาวนิวโทรฟิลต่ำและแอกรานูโลไซโตซิส, ภาวะความดันโลหิตต่ำ, ภาวะต่อมพาราไทรอยด์ทำงานเกิน
- **ปฏิกิริยาระหว่างยา** (ระดับปานกลาง พบทั้งหมด 100 รายการ ตัวอย่างหลัก): กลุ่มคอร์ติโคสเตียรอยด์ (Hydrocortisone, Betamethasone, Budesonide, Dexamethasone), Aprepitant, Acetylsalicylic acid, Bupropion, เกลือแคลเซียมหลายชนิด, Canagliflozin, Dapagliflozin, Clarithromycin, Clotrimazole

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายอยู่ที่ระดับหลักฐาน L5 คือมีเพียงคะแนนจากโมเดล ไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุน และใบอนุญาตเดียวในประเทศไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ค้นหาและทบทวนหลักฐานทางคลินิกหรือก่อนคลินิกเกี่ยวกับ Amlodipine ในภาวะสมองขาดเลือดบริเวณก้านสมอง
- เพิ่มข้อมูลกลไกการออกฤทธิ์ (MOA) จาก DrugBank
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจาก อย. ไทย เพื่อประเมินคำเตือนและข้อห้ามใช้
- ตรวจสอบสถานะทะเบียนยาในไทย เนื่องจากปัจจุบันไม่มีทะเบียนที่ยังใช้งานได้
- ประเมินความเหมาะสมของรูปแบบยาและช่องทางการให้ยา (ยาเม็ดรับประทาน) กับผู้ป่วยหลอดเลือดสมองเฉียบพลัน
- พิจารณาข้อบ่งใช้ใหม่อื่นที่มีหลักฐานมากกว่า เช่น ภาวะความดันปอดสูงจากโรคปอดและ/หรือภาวะพร่องออกซิเจน (หลักฐาน L4 แต่เป็นข้อมูลก่อนคลินิกและรายงานผู้ป่วย และมีความกังวลว่ายาขยายหลอดเลือดอาจทำให้ความสัมพันธ์ระหว่างการระบายอากาศและการไหลเวียนเลือดในปอดแย่ลง)

จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
