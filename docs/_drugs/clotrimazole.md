## Clotrimazole: ยาต้านเชื้อรากลุ่มอะโซล (ยับยั้งเอนไซม์ CYP51) → สิวอักเสบ (acne (disease))
{: .text-alpha }

## สรุปสั้นๆ

Clotrimazole เป็นยาต้านเชื้อรากลุ่มอะโซล ออกฤทธิ์ยับยั้งการสร้างเออร์โกสเตอรอลของเชื้อรา
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **สิวอักเสบ (acne (disease))**
หลักฐานยังอ่อนมาก มี **การทดลองทางคลินิก 1 รายการ** ซึ่งเป็นยาสูตรผสมสามชนิด และถูกระงับไว้ ไม่มีวรรณกรรมที่ศึกษาโรคนี้โดยตรง

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ไม่มีบันทึกในข้อมูลท้องถิ่น |
| ข้อบ่งใช้ใหม่ที่ทำนาย | สิวอักเสบ (acne (disease)) |
| คะแนนการทำนาย TxGNN | 0.9986 |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | อยู่ในบัญชียาหลักแห่งชาติ (1 จาก 1 รายการ) – ข้อมูลนี้ไม่รวมสถานะทะเบียนตำรับยาของ อย. |
| จำนวนรายการในบัญชียาหลักแห่งชาติ | 1 รายการ (ยังมีผล 1) |
| คำแนะนำในการตัดสินใจ | Hold |

หมายเหตุเรื่องระดับหลักฐาน: การทดลองเดียวที่พบ (NCT01244256) ศึกษายาสูตรผสม clotrimazole + gentamicin + beclomethasone ในภาวะผิวหนังอักเสบติดเชื้อ ไม่แยกผลของ clotrimazole และไม่มีผลรายงาน จึงไม่ถือว่าเป็นการศึกษาสิวโดยตรงที่ยืนยันได้ ระดับหลักฐานจึงเป็น L5

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวม ตามที่ทราบทั่วไป clotrimazole เป็นยาต้านเชื้อราสังเคราะห์กลุ่มอะโซล ยับยั้งเอนไซม์ CYP51 (lanosterol 14-alpha-demethylase) ทำให้การสร้างเออร์โกสเตอรอลและความสมบูรณ์ของเยื่อหุ้มเซลล์เชื้อราเสียไป

ในเชิงกลไก การลดการเจริญของเชื้อรา เช่น Malassezia หรือ Candida บนผิวหนัง อาจช่วยลดรอยโรคคล้ายสิวที่เกิดจากการอักเสบได้บางส่วน แต่เป็นเพียงสมมติฐาน การทดลองเดียวที่มีเป็นยาสูตรผสมสามชนิด จึงแยกผลของ clotrimazole ออกมาไม่ได้ คะแนนสูงของโมเดลจึงยังเป็นเพียงการทำนาย

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: พบรายการปฏิกิริยาระหว่างยาจำนวนมาก (รวม 100 รายการ) ตัวอย่างระดับรุนแรง (Major) ได้แก่ fentanyl, alfentanil, amiodarone และ hydrocodone ส่วนระดับปานกลาง เช่น paclitaxel, abemaciclib, acalabrutinib, nifedipine, amlodipine, apixaban, aprepitant, alprazolam, estradiol, levonorgestrel และ norethisterone

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาไทยยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ยังไม่มีการศึกษาที่ยืนยันผลของ clotrimazole ต่อสิวโดยตรง การทดลองเดียวเป็นยาสูตรผสมและถูกระงับ ระดับหลักฐานจึงเป็น L5 และคะแนนโมเดลสูงอย่างเดียวไม่เพียงพอต่อการตัดสินใจ

**หากต้องการดำเนินการต่อต้อง:**
- การศึกษาที่ทดสอบ clotrimazole ตัวเดียวในผู้ป่วยสิวโดยตรง
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียด และความเกี่ยวข้องของเชื้อรากับการเกิดสิว
- คำเตือนและข้อห้ามใช้จากเอกสารกำกับยาไทย
- ยืนยันสถานะใบอนุญาตและรูปแบบยาที่เหมาะสมกับผิวหนัง (ใบอนุญาตที่มีเป็นยาเม็ดรับประทาน)
