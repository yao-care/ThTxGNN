# Potassium chloride: จากภาวะโพแทสเซียมต่ำสู่ภาวะกรดในท่อไต (Renal Tubular Acidosis)

## สรุปสั้นๆ

Potassium chloride เดิมใช้รักษาภาวะโพแทสเซียมต่ำ โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ภาวะกรดในท่อไต (Renal Tubular Acidosis, RTA)** โดยมี **วรรณกรรม 20 ฉบับ** แต่ **ยังไม่มีการทดลองทางคลินิกที่ลงทะเบียน** หลักฐานส่วนใหญ่เป็นรายงานผู้ป่วยและบทความทบทวน ซึ่งสะท้อนการใช้เป็นการเสริมโพแทสเซียมเพื่อบรรเทาอาการ ไม่ใช่การรักษาตัวโรค

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | โพแทสเซียมต่ำ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ภาวะกรดในท่อไต (Renal Tubular Acidosis) |
| คะแนนการทำนาย TxGNN | 99.87% |
| ระดับหลักฐาน | L4 (ไม่มี RCT มีเพียงรายงานผู้ป่วย การศึกษาแบบ cohort และบทความทบทวน) |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีใบอนุญาตที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Potassium chloride เป็นเกลือโพแทสเซียมที่ใช้ทดแทนโพแทสเซียมในร่างกาย ประสิทธิผลในการแก้ภาวะโพแทสเซียมต่ำได้รับการยอมรับแล้ว

ในภาวะกรดในท่อไตส่วนปลาย (distal RTA) ไตสูญเสียโพแทสเซียมจนเกิดภาวะโพแทสเซียมต่ำ บางรายรุนแรงถึงอ่อนแรงหรืออัมพาต รายงานผู้ป่วยหลายฉบับระบุว่าให้ potassium chloride ทั้งทางหลอดเลือดดำและทางปากเพื่อแก้ภาวะนี้ เช่น กรณีที่เกี่ยวข้องกับโรค Sjögren

ต้องเข้าใจข้อจำกัดให้ชัดเจน คือยานี้ช่วย **ทดแทนโพแทสเซียมที่สูญเสียไป** เท่านั้น ไม่ได้แก้ความผิดปกติของท่อไต การรักษาหลักของ RTA ยังคงเป็นการให้ด่าง (alkali therapy)

## ข้อพิจารณาด้านความปลอดภัย

**ข้อห้ามใช้/โรคที่ควรระวัง (จากฐานความรู้ TxGNN ไม่ใช่ข้อความจากเอกสารกำกับยา):** ฐานความรู้ระบุความสัมพันธ์ข้อห้ามใช้กับโรคจำนวนมาก ที่สำคัญได้แก่
- โรคไตและภาวะปัสสาวะไม่ออก (anuria)
- โรคหัวใจ หัวใจล้มเหลว โรคหลอดเลือดหัวใจ
- แผลในกระเพาะอาหารและโรคแผลเปปติก
- ตับอ่อนอักเสบ โรคตับ โรคถุงน้ำดี
- ความดันโลหิตสูง ลมชัก โรคปอดอุดกั้นเรื้อรัง
- ภาวะแคลเซียมสูง โรค sarcoidosis ภาวะเหล็กเกิน (hemochromatosis, hemosiderosis) โรค Wilson

**ปฏิกิริยาระหว่างยา:** ข้อมูลที่รวบรวมพบ 100 รายการ ที่สำคัญระดับรุนแรง (Major) ได้แก่
- ยาที่เพิ่มโพแทสเซียมในเลือด: amiloride, benazepril, olmesartan, valsartan, azilsartan medoxomil
- ยาต้านโคลิเนอร์จิก: atropine, hyoscyamine, homatropine, glycopyrronium, benzatropine, biperiden
- ยาแก้แพ้และยาอื่น: chlorpheniramine, brompheniramine, acrivastine, phenyltoloxamine, amitriptyline
- ระดับปานกลาง: ibuprofen, ketorolac, aliskiren

**ข้อสังเกตจากวรรณกรรม:** มีรายงานว่ายาเม็ดโพแทสเซียมคลอไรด์ทำให้เกิดการระคายเคืองและแผลในทางเดินอาหารส่วนบน

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- หลักฐานอยู่ที่ระดับ L4 ไม่มีการทดลองทางคลินิก และยาทำหน้าที่เพียงทดแทนโพแทสเซียม ไม่ได้รักษา RTA โดยตรง ซึ่งโดยหลักการก็เป็นการใช้ตามข้อบ่งใช้เดิมอยู่แล้ว (แก้โพแทสเซียมต่ำ) ไม่ใช่ข้อบ่งใช้ใหม่ที่แท้จริง
- ใบอนุญาตในไทยถูกยกเลิกแล้ว และยังขาดข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจากเว็บไซต์ อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ตรวจสอบความเกี่ยวข้องของวรรณกรรมที่ยังไม่ได้ประเมิน และกำหนดให้ชัดว่าเป็นการรักษาแบบประคับประคอง (ทดแทนโพแทสเซียม) ควบคู่กับการให้ด่าง
- หากต้องการวางจำหน่ายในไทย ต้องยื่นขึ้นทะเบียนใหม่หรือตรวจสอบสถานะผลิตภัณฑ์ที่มีอยู่
- ประเมินความเสี่ยงต่อทางเดินอาหารและระดับโพแทสเซียมสูงเกิน โดยเฉพาะในผู้ป่วยโรคไตหรือผู้ที่ใช้ยากลุ่ม ACEI/ARB

*ข้อบ่งใช้ลำดับอื่นที่โมเดลทำนาย (HELIX syndrome, Alstrom syndrome, Pendred syndrome, dyspepsia, Senior-Loken syndrome, congenital prothrombin deficiency, gastroduodenitis, NAD(P)HX dehydratase deficiency, stomach disease) อยู่ที่ระดับ L5 ทั้งหมดและแนะนำให้ Hold โดยเฉพาะโรคทางเดินอาหาร ซึ่งวรรณกรรมชี้ว่ายานี้เป็นสาเหตุของการบาดเจ็บ ไม่ใช่การรักษา*
