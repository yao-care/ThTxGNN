# Hydrochlorothiazide: จากความดันโลหิตสูงและบวมน้ำ สู่โรคไตจากความดันโลหิตสูงรุนแรง (Malignant Hypertensive Renal Disease)

## สรุปสั้นๆ

Hydrochlorothiazide เป็นยาขับปัสสาวะกลุ่มไทอาไซด์ เดิมใช้รักษาความดันโลหิตสูงและอาการบวมน้ำ
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **โรคไตจากความดันโลหิตสูงรุนแรง (Malignant Hypertensive Renal Disease)** ด้วยคะแนนสูง
อย่างไรก็ตาม ข้อบ่งใช้ลำดับนี้ **ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุนเลย** จึงเป็นเพียงการทำนายจากโมเดล

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ความดันโลหิตสูง, บวมน้ำ |
| ข้อบ่งใช้ใหม่ที่ทำนาย | โรคไตจากความดันโลหิตสูงรุนแรง (Malignant Hypertensive Renal Disease) |
| คะแนนการทำนาย TxGNN | 98.42% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกแล้วทั้งหมด (ไม่มีใบอนุญาตที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลที่รวบรวมไว้ แต่จากความรู้ทางเภสัชวิทยา Hydrochlorothiazide ยับยั้งตัวขนส่ง Na-Cl ที่ท่อไตส่วนต้นช่วงขดปลาย (distal convoluted tubule) ทำให้ปริมาตรของเหลวลดลงและความดันโลหิตลดลง ประสิทธิผลในความดันโลหิตสูงทั่วไปเป็นที่ยอมรับแล้ว

ความเชื่อมโยงกับโรคไตจากความดันโลหิตสูงรุนแรงจึงอยู่ที่ "ความดันโลหิตสูง" เหมือนกัน แต่ยานี้ **ไม่ใช่ยามาตรฐานสำหรับภาวะความดันสูงฉุกเฉินหรือ malignant nephrosclerosis** ความเชื่อมโยงนี้จึงอาศัยเพียงผลทำนายของโมเดลเท่านั้น

ข้อพึงระวัง: การทำนายอันดับอื่นของยานี้ก็ยังไม่มีหลักฐานโดยตรงเช่นกัน มีเพียงโรคหัวใจจากปอด (chronic/acute pulmonary heart disease) ที่มีหลักฐานทางอ้อมจากการใช้ขับปัสสาวะในภาวะหัวใจล้มเหลว (ระดับ L4 คำแนะนำ "Research Question")

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบถ้วน กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

- **โรคที่เกี่ยวข้องกับข้อห้ามใช้ (จากกราฟความรู้ของโมเดล ไม่ใช่ข้อความในฉลากยา)**: โรคตับและตับวาย ตับแข็ง โรคไต ตับอ่อนอักเสบ โรคถุงน้ำดี แผลในกระเพาะอาหาร โรคพอร์ไฟเรีย โรคลูปัส (SLE) โลหิตจางจากภูมิต้านตนเอง โรคกล้ามเนื้อและอัมพาตเป็นช่วงตามพันธุกรรม หอบหืด หลอดลมอักเสบ ภาวะ angioedema ลมชัก และโรควิตกกังวล/ความผิดปกติทางอารมณ์บางชนิด
- **ปฏิกิริยาระหว่างยา**: พบรายการปฏิกิริยาระหว่างยาทั้งหมด 100 รายการ ส่วนใหญ่ระดับปานกลาง ตัวอย่างเช่น ยาเบาหวาน (acarbose, acetohexamide, alogliptin, albiglutide), คอร์ติโคสเตียรอยด์ (hydrocortisone, betamethasone, beclomethasone), amphotericin B ทุกรูปแบบ, วิตามินดีและอนุพันธ์ (cholecalciferol, calcifediol, calcitriol), rabeprazole, bupropion และ bisacodyl ส่วน doxycycline และ atropine เป็นระดับเล็กน้อย
- **สัญญาณความปลอดภัยจากวรรณกรรม**: มีรายงานผู้ป่วยภาวะปอดบวมน้ำที่สัมพันธ์กับ hydrochlorothiazide (Chest, 1989) ซึ่งสำคัญเมื่อพิจารณาใช้ในโรคปอดหรือความดันปอดสูง

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล (L5) ไม่มีการทดลองทางคลินิกหรือวรรณกรรม และยานี้ไม่ใช่ยามาตรฐานสำหรับภาวะนี้ นอกจากนี้ใบอนุญาตในไทยถูกยกเลิกแล้ว และข้อมูลความปลอดภัยจากเอกสารกำกับยายังขาด

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจเอกสารกำกับยาจาก อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้ที่ครบถ้วน (เป็นข้อมูลที่ขาดและเป็นอุปสรรคต่อการคัดกรองความปลอดภัย)
- เติมข้อมูลกลไกการออกฤทธิ์ (MOA) จาก DrugBank
- ทบทวนวรรณกรรมและค้นหาการทดลองทางคลินิกที่เกี่ยวข้องกับโรคไตจากความดันโลหิตสูงรุนแรงโดยเฉพาะ
- ตรวจสอบสถานะทะเบียนยาในไทย เพราะปัจจุบันไม่มีใบอนุญาตที่ยังใช้ได้
- หากต้องการเดินหน้าทางเลือกอื่น ควรพิจารณาโรคหัวใจจากปอด (L4) เป็นคำถามวิจัยลำดับต้น โดยระวังสัญญาณปอดบวมน้ำ
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
