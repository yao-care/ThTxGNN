# Vitamin D: จากภาวะขาดวิตามินดีสู่ความผิดปกติของการหลั่งสารจากเกล็ดเลือดแบบปฐมภูมิ (Primary Release Disorder of Platelets)

## สรุปสั้นๆ

Vitamin D เดิมใช้ป้องกันและรักษาภาวะขาดวิตามินดี โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ความผิดปกติของการหลั่งสารจากเกล็ดเลือดแบบปฐมภูมิ (Primary Release Disorder of Platelets)** เป็นอันดับแรก แต่ข้อมูลที่รวบรวมสำหรับรายงานนี้ยังไม่มีการทดลองทางคลินิก และมีวรรณกรรมเพียง 3 ฉบับที่ไม่เกี่ยวข้องโดยตรง จึงถือว่า **หลักฐานสนับสนุนอ่อนมาก** ส่วนข้อบ่งใช้ที่ทำนายไว้ซึ่งมีหลักฐานเด่นกว่า ได้แก่ **ท่อน้ำดีอักเสบแข็ง (Sclerosing Cholangitis)** และ **ภาวะพาราไทรอยด์ทำงานต่ำ (Hypoparathyroidism)**

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียด ตามข้อมูลที่ทราบ Vitamin D เป็นวิตามินที่ละลายในไขมัน มีบทบาทสำคัญต่อสมดุลแคลเซียมและการปรับภูมิคุ้มกัน ประสิทธิผลในการรักษาภาวะขาดวิตามินดีได้รับการยอมรับแล้ว

ในเชิงทฤษฎี การส่งสัญญาณของแคลเซียมและการปรับภูมิคุ้มกันอาจเกี่ยวข้องกับการทำงานของเกล็ดเลือด แต่ยังไม่มีหลักฐานโดยตรงที่เชื่อมวิตามินดีกับความผิดปกติของการหลั่งสารจากเกล็ดเลือด การจับคู่นี้อาศัยการทำนายของโมเดลเพียงอย่างเดียว

**ข้อบ่งใช้อื่นที่มีเหตุผลเชิงกลไกชัดเจนกว่า**
- **ท่อน้ำดีอักเสบแข็ง (คะแนน 92.38%, L3):** ภาวะขาดวิตามินดีพบบ่อยในโรคทางเดินน้ำดีคั่งเพราะการดูดซึมวิตามินที่ละลายในไขมันบกพร่อง งานศึกษาเชิงสังเกตพบว่าการขาดวิตามินดีรุนแรงสัมพันธ์กับการพยากรณ์โรค PSC ที่แย่ลง และการเสริมวิตามินดีสัมพันธ์กับความเสี่ยงมะเร็งทางเดินตับและน้ำดีที่ต่ำลง รวมถึงมีการศึกษาในหนูที่แสดงว่าวิตามินดีปรับพังผืดในท่อน้ำดี
- **ภาวะพาราไทรอยด์ทำงานต่ำ (คะแนน 84.07%, L4):** เมื่อไม่มี PTH การกระตุ้นวิตามินดีที่ไตบกพร่อง จึงสมเหตุสมผลในเชิงกลไก แต่หลักฐานที่มีเป็นบทความทบทวนและการทดลองที่เกี่ยวข้องทางอ้อม และต้องระวังภาวะแคลเซียมในเลือดสูง

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้องกับความผิดปกติของการหลั่งสารจากเกล็ดเลือดแบบปฐมภูมิ

## หลักฐานจากวรรณกรรม

วรรณกรรมที่พบมีเพียง 3 ฉบับ และไม่ได้ศึกษาผลของวิตามินดีต่อโรคนี้โดยตรง

| PMID | ปี | ประเภท | วารสาร | ผลลัพธ์หลัก |
|------|-----|------|------|---------|
| [31637855](https://pubmed.ncbi.nlm.nih.gov/31637855/) | 2019 | Cohort | J Vet Emerg Crit Care | ศึกษาระดับวิตามินดี 25-OH-D ในสุนัขป่วยหนักใน ICU ไม่เกี่ยวข้องกับโรคเกล็ดเลือดโดยตรง |
| [42016165](https://pubmed.ncbi.nlm.nih.gov/42016165/) | 2026 | Cohort | Int J Chron Obstruct Pulmon Dis | การศึกษา Mendelian randomization เชื่อมสารเมแทบอไลต์ในเลือด (รวมวิตามินดี) กับ COPD ในประชากรเอเชียตะวันออก ไม่เกี่ยวข้องกับโรคเกล็ดเลือด |
| [27885969](https://pubmed.ncbi.nlm.nih.gov/27885969/) | 2016 | Review | Crit Care | บทคัดย่อการประชุมด้านเวชบำบัดวิกฤต ไม่เกี่ยวข้องโดยตรง |

|---------|------|------|-----------|

## ข้อพิจารณาด้านความปลอดภัย

**ปฏิกิริยาระหว่างยา:** พบข้อมูลปฏิกิริยาระหว่างยารวม 79 รายการ แต่ยังไม่ได้จัดระดับความรุนแรง ตัวอย่างยาที่พบ ได้แก่ Calcitriol, Vitamin A, Doxycycline, Acetylsalicylic acid, Dexamethasone, Prednisone, Omeprazole, Pantoprazole, Metformin และ Morphine

**ข้อควรระวังจากเอกสารประกอบ:** วิตามินดีอาจทำให้แคลเซียมในเลือดสูงขึ้น ซึ่งต้องติดตามอย่างใกล้ชิดในผู้ป่วยโรคพาราไทรอยด์ (เช่น ภาวะพาราไทรอยด์ทำงานเกินใน MEN)

คำเตือนและข้อห้ามใช้ตามเอกสารกำกับยา กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้อันดับแรกมีเพียงการทำนายจากโมเดล (L5) ไม่มีการทดลองทางคลินิก และวรรณกรรมที่พบไม่เกี่ยวข้องโดยตรง นอกจากนี้ทะเบียนยาในไทยถูกยกเลิกทั้งหมดแล้ว
- หากต้องการเลือกแนวทางที่มีแนวโน้มดีที่สุด ท่อน้ำดีอักเสบแข็ง (L3) ควรเป็นคำถามวิจัยต่อไป

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์ (MOA) โดยละเอียดจาก DrugBank
- คำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- หลักฐานที่ศึกษาวิตามินดีโดยตรงต่อการทำงานของเกล็ดเลือด หรือพิจารณาเปลี่ยนไปศึกษาท่อน้ำดีอักเสบแข็งที่มีการวิจัยสนับสนุนมากกว่า
- ทบทวนสถานะทะเบียนยาในไทย เนื่องจากทะเบียนที่มีอยู่ถูกยกเลิกแล้ว
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
