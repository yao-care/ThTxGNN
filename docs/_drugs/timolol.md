# Timolol: จากต้อหินสู่ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม (Primary Hereditary Glaucoma)

## สรุปสั้นๆ

Timolol เป็นยาหยอดตากลุ่มต้านเบต้า (beta-blocker) ซึ่งเดิมใช้รักษา **ต้อหิน**
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม (Primary Hereditary Glaucoma)**
แต่ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมที่เกี่ยวข้องโดยตรง** การคาดการณ์นี้จึงมาจากโมเดลเพียงอย่างเดียว

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ต้อหิน |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม (Primary Hereditary Glaucoma) |
| คะแนนการทำนาย TxGNN | 98.64% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ข้อมูลกลไกการออกฤทธิ์โดยละเอียดของยายังไม่ครบ แต่ตามข้อมูลที่ทราบ Timolol เป็นยาต้านเบต้าแบบไม่เลือกจับ (non-selective beta-blocker) ประสิทธิผลในการรักษาต้อหินที่เป็นข้อบ่งใช้เดิมได้รับการพิสูจน์แล้ว

ยานี้ลดความดันลูกตา (IOP) โดยลดการสร้างน้ำในลูกตา (aqueous humor) ในเชิงกลไก หลักการเดียวกันนี้อาจใช้กับต้อหินชนิดถ่ายทอดทางพันธุกรรมได้ เพราะต้อหินกลุ่มนี้มีความดันลูกตาสูงเป็นปัจจัยหลักเช่นกัน และข้อบ่งใช้ใหม่ที่ทำนายอยู่ในกลุ่มโรคต้อหินเดียวกับข้อบ่งใช้เดิม

อย่างไรก็ตาม ความสมเหตุสมผลนี้เป็นเพียงการอนุมานจากกลไก ยังไม่มีหลักฐานจากการศึกษาจริงในโรคนี้

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อมูลการวางจำหน่ายในประเทศไทย

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ |
|---------|------|------|-----------|
| ทะเบียนยาเลขที่ 1A 99/67 (สถานะ: ถูกยกเลิก) | Timolol | ยาหยอดตา | ต้อหิน |

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: ข้อมูลที่รวบรวมพบรายการที่อาจเกิดปฏิกิริยากับ Timolol รวม 100 รายการ รายการหลักได้แก่
  - **ระดับรุนแรง (Major)**: Epinephrine
  - **ระดับปานกลาง (Moderate)**: ยากลุ่มคอร์ติโคสเตียรอยด์ (Hydrocortisone, Dexamethasone, Betamethasone, Triamcinolone, Budesonide), Atropine, Hyoscyamine, Dicyclomine, Morphine, Bupropion, Cimetidine, Lorcaserin, ยาเบาหวาน (Canagliflozin, Dapagliflozin, Chlorpropamide) และเกลือแคลเซียม (Calcium phosphate, Calcium acetate)
  - **ระดับเล็กน้อย (Minor)**: Acetylsalicylic acid, Magnesium oxide
- **โรคหรือภาวะที่ฐานความรู้เชิงกราฟของ TxGNN ระบุว่าควรระวัง** (ไม่ได้มาจากเอกสารกำกับยา) ได้แก่
  - ความดันโลหิตต่ำเมื่อเปลี่ยนท่า (orthostatic hypotension) และกลุ่มอาการ POTS
  - โรคไต โรคตับ ตับอ่อนอักเสบ และโรคถุงน้ำดี
  - เบาหวานและภาวะ diabetic ketoacidosis
  - โรคเอสแอลอี (SLE)
  - โรคเกาต์
  - โรคกล้ามเนื้ออ่อนแรง (myasthenia gravis) และโรคของรอยต่อประสาทกับกล้ามเนื้อ
  - ภาวะผิดปกติของแคลเซียม ฟอสฟอรัส และโพแทสเซียม
  - โรควิตกกังวลและภาวะซึมเศร้าเรื้อรังชนิดอ่อน (dysthymic disorder)
- คำเตือนหลักและข้อห้ามใช้จากเอกสารกำกับยาในไทยยังไม่มีข้อมูล กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ใหม่นี้มีเพียงคะแนนจากโมเดล (98.64%) ไม่มีทั้งการทดลองทางคลินิกและวรรณกรรมสนับสนุน จึงอยู่ที่ระดับหลักฐาน L5
- ทะเบียนยาในไทยเพียงฉบับเดียวถูกยกเลิกแล้ว และข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบ

**หากต้องการดำเนินการต่อต้อง:**
- ค้นหาหลักฐานทางคลินิกหรือวรรณกรรมที่ศึกษา Timolol ในต้อหินชนิดถ่ายทอดทางพันธุกรรมโดยตรง
- รวบรวมข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- ดาวน์โหลดและตรวจเอกสารกำกับยาจากเว็บไซต์ อย. เพื่อให้ได้คำเตือนและข้อห้ามใช้ที่เป็นทางการ
- ตรวจสอบสถานะทะเบียนผลิตภัณฑ์ที่มี Timolol ในไทย รวมถึงสูตรผสม เพราะทะเบียนเดี่ยวที่พบถูกยกเลิกแล้ว
- ข้อสังเกต: ข้อบ่งใช้อื่นที่โมเดลทำนายในกลุ่มต้อหิน เช่น **ต้อหินมุมปิด (closed-angle / angle-closure glaucoma)** และ **ต้อหินมุมเปิด (glaucoma 1, open angle)** มีหลักฐานทางคลินิกและวรรณกรรมมากกว่า และถูกจัดอยู่ที่ระดับ L1 (Proceed with Guardrails) จึงควรพิจารณาประเมินแยกเป็นรายงานต่างหาก
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
