# Clindamycin: จากโรคติดเชื้อแบคทีเรียสู่โรคกระจกตาและเยื่อบุตาอักเสบแบบจุด (Punctate Epithelial Keratoconjunctivitis)

## สรุปสั้นๆ

Clindamycin เป็นยาปฏิชีวนะที่เดิมใช้รักษาโรคติดเชื้อแบคทีเรีย โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **โรคกระจกตาและเยื่อบุตาอักเสบแบบจุด (Punctate Epithelial Keratoconjunctivitis)** อย่างไรก็ตาม **ยังไม่มีการทดลองทางคลินิกและไม่มีวรรณกรรม** สนับสนุนข้อบ่งใช้นี้ จึงเป็นเพียงการทำนายจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | โรคติดเชื้อแบคทีเรีย |
| ข้อบ่งใช้ใหม่ที่ทำนาย | โรคกระจกตาและเยื่อบุตาอักเสบแบบจุด (Punctate Epithelial Keratoconjunctivitis) |
| คะแนนการทำนาย TxGNN | 99.97% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ✗ ใบอนุญาตถูกยกเลิกทั้งหมด |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลยา ตามข้อมูลที่ทราบ Clindamycin เป็นยาปฏิชีวนะที่ยับยั้งการสังเคราะห์โปรตีนของแบคทีเรียผ่านไรโบโซมหน่วย 50S ประสิทธิผลในการรักษาโรคติดเชื้อแบคทีเรียได้รับการพิสูจน์แล้ว

ในเชิงทฤษฎี กลไกนี้อาจช่วยในโรคของผิวดวงตาที่มีแบคทีเรียเกี่ยวข้อง แต่โรคกระจกตาและเยื่อบุตาอักเสบแบบจุดมักเกิดจากไวรัสหรือสาเหตุที่ไม่ใช่การติดเชื้อ ซึ่ง Clindamycin ไม่ได้ออกฤทธิ์ต่อเป้าหมายเหล่านี้ จึงยังไม่มีหลักฐานรองรับการใช้ในข้อบ่งใช้นี้

ข้อบ่งใช้ที่ทำนายอื่นๆ ส่วนใหญ่ก็เป็นโรคตา (เช่น exposure keratitis ซึ่งมีเพียงวรรณกรรมเกี่ยวกับกระจกตาอักเสบจากการติดเชื้อ ไม่ใช่โรคนั้นโดยตรง) และยังไม่มีหลักฐานสนับสนุนเช่นกัน

## ข้อพิจารณาด้านความปลอดภัย

- **โรคที่เกี่ยวข้องกับข้อห้ามใช้จากฐานความรู้ (knowledge graph)**: ข้อมูลนี้ไม่ได้มาจากเอกสารกำกับยา ได้แก่ ตับวาย, โรคโครห์น, โรคลำไส้อักเสบ (IBD), ลำไส้ใหญ่อักเสบเรื้อรังแบบแผลเปื่อย, โรคท้องร่วง, ลำไส้ใหญ่อักเสบจาก *Clostridium difficile*, ลำไส้เน่าในทารกแรกเกิด, ผิวหนังอักเสบ (รวมผิวหนังอักเสบภูมิแพ้และผิวหนังลอกเป็นแผ่น), ผิวไหม้แดด และการติดเชื้อราในช่องคลอด
- **ปฏิกิริยาระหว่างยา**: พบรายการที่ระดับปานกลาง (Moderate) ได้แก่ Balsalazide, Clarithromycin, Picosulfuric acid, Attapulgite และ Kaolin นอกจากนี้ยังมีรายการที่ยังไม่ระบุระดับความรุนแรง เช่น Amphotericin B, Acetylsalicylic acid, Amoxicillin, Doxycycline, Vancomycin และ Morphine (รวมทั้งหมด 100 รายการที่พบ แสดงเฉพาะรายการหลัก)

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาไทยยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ใหม่นี้มีเพียงคะแนนจากโมเดล (L5) ไม่มีการทดลองทางคลินิกหรือวรรณกรรม และสาเหตุของโรคมักไม่ใช่แบคทีเรีย
- ใบอนุญาตในประเทศไทยถูกยกเลิกทั้งหมด และข้อมูลความปลอดภัยจากเอกสารกำกับยายังขาด

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจาก อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ทบทวนวรรณกรรมและการศึกษาก่อนคลินิกที่เกี่ยวกับ Clindamycin ในโรคผิวตา
- ประเมินความเข้ากันได้ของช่องทางการให้ยา (ปัจจุบันมีเฉพาะยาเม็ดชนิดรับประทาน ซึ่งไม่เหมาะกับโรคตา)
- พิจารณาข้อบ่งใช้อื่นที่ทำนาย เช่น exposure keratitis ซึ่งมีวรรณกรรมเกี่ยวกับกระจกตาอักเสบติดเชื้อ (ระดับ L4) เป็นคำถามวิจัยต่อไป
