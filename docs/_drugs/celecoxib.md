## Celecoxib: จากการบรรเทาปวดและข้อเสื่อมสู่ acromesomelic dysplasia ชนิด Hunter-Thompson
{: .text-alpha }

## สรุปสั้นๆ

Celecoxib เดิมใช้บรรเทาปวดและรักษาข้อเสื่อม โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **Acromesomelic dysplasia ชนิด Hunter-Thompson** ซึ่งเป็นโรคกระดูกผิดปกติทางพันธุกรรม ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรม** สนับสนุน การคาดการณ์นี้จึงมาจากโมเดลเพียงอย่างเดียว

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | บรรเทาปวด, ข้อเสื่อม |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Acromesomelic dysplasia, Hunter-Thompson type |
| คะแนนการทำนาย TxGNN | 0.9988 |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | วางจำหน่าย (ทะเบียนที่ยังมีผล 27 จาก 49 รายการ) |
| จำนวนทะเบียนตำรับยา | 49 รายการ (ยังมีผล 27) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมไว้ ตามข้อมูลที่ทราบ Celecoxib เป็นยากลุ่ม NSAID ที่ยับยั้งเอนไซม์ COX-2 แบบจำเพาะ ทำให้การสร้างพรอสตาแกลนดิน E2 ลดลง จึงบรรเทาอาการปวดและการอักเสบได้ ประสิทธิผลในการบรรเทาปวดและข้อเสื่อมได้รับการพิสูจน์แล้ว

โรคเป้าหมายเป็นความผิดปกติของโครงกระดูกที่เกี่ยวข้องกับยีน GDF5 ปัจจุบันยังไม่มีหลักฐานว่ากลไกของโรคนี้ขับเคลื่อนด้วยพรอสตาแกลนดิน ความเชื่อมโยงทางกลไกจึงอ่อน และตอนนี้พึ่งพาคะแนนทำนายของโมเดลเป็นหลัก

คะแนนที่สูงมาก (0.9988) ไม่ได้แปลว่ามีหลักฐานทางคลินิก เพราะเป็นคะแนนจากโมเดล TxGNN (deep learning) ซึ่งอาจสะท้อนความคล้ายคลึงระหว่างโรคที่เกี่ยวข้องกันที่โมเดลเรียนรู้มา ไม่ใช่หลักฐานทางชีวภาพ

## ข้อพิจารณาด้านความปลอดภัย

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

- **โรคที่กราฟความรู้ระบุว่าเป็นข้อห้ามหรือควรระวัง** (ไม่ใช่ข้อความจากฉลากยา): โรคความดันโลหิตสูง, โรคไต, โรคตับ, โรคถุงน้ำดี, หัวใจล้มเหลว, โรคหัวใจและหลอดเลือด, กล้ามเนื้อหัวใจตายและหลอดเลือดหัวใจอุดตัน, โรคหลอดเลือดสมอง (รวมสมองขาดเลือด), แผลในกระเพาะอาหาร/ลำไส้ส่วนต้น (รวมแผลที่กำลังเป็นอยู่), โรคหืดทุกชนิด, การใช้สารเสพติด/การติดสาร, โรคโลหิตจาง และโรคฮีโมโกลบินผิดปกติ
- **ปฏิกิริยาระหว่างยา**: พบรายการที่บันทึกไว้ 100 รายการ รายการหลักที่แสดงได้มีดังนี้
  - ระดับ **Major**: Eliglustat
  - ระดับ **Moderate**: Hydrocortisone, Metformin, ยาเบาหวานกลุ่มซัลโฟนิลยูเรียและกลุ่มใกล้เคียง (Acetohexamide, Chlorpropamide, Glimepiride, Glipizide, Glyburide, Nateglinide), Exenatide, Cimetidine, Levofloxacin, Metronidazole, Kanamycin, Naltrexone, Fenfluramine, Dexfenfluramine, Balsalazide, Mesalazine, Olsalazine

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ใหม่นี้มีเพียงคะแนนทำนายจากโมเดล ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับ และไม่มีกลไกที่เชื่อมโยงกับ COX-2 ได้ชัดเจน
- ใบอนุญาตในไทยถูกยกเลิกแล้ว และข้อมูลความปลอดภัยจากเอกสารกำกับยายังไม่ครบ

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและตรวจเอกสารกำกับยาจากเว็บไซต์ อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้ที่เป็นทางการ
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- ทำการศึกษากลไกหรือก่อนคลินิกที่แสดงว่าพรอสตาแกลนดิน/COX-2 เกี่ยวข้องกับพยาธิสภาพของโรคนี้
- ตรวจสอบสถานะใบอนุญาต เพราะปัจจุบันยาไม่มีทะเบียนที่ยังใช้ได้ในประเทศไทย
