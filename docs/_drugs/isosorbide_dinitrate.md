# Isosorbide dinitrate: จากโรคหัวใจขาดเลือดสู่ผมร่วง (Alopecia)

## สรุปสั้นๆ

Isosorbide dinitrate เป็นยาในกลุ่มไนเตรต ใช้รักษาโรคหัวใจขาดเลือดตามทะเบียนยาในประเทศไทย โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **ผมร่วง (Alopecia)** แต่ **ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุนเลย** การทำนายนี้จึงมาจากโมเดลเพียงอย่างเดียว

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | โรคหัวใจขาดเลือด |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ผมร่วง (Alopecia) |
| คะแนนการทำนาย TxGNN | 99.99% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ข้อมูลที่รวบรวมสำหรับรายงานนี้ยังขาดรายละเอียดกลไกการออกฤทธิ์ของยาจากฐานข้อมูลยา อย่างไรก็ตาม ตามที่ทราบกันทั่วไป Isosorbide dinitrate เป็นตัวให้ไนตริกออกไซด์ (NO donor) ซึ่งทำให้หลอดเลือดขยายตัว และเป็นเหตุผลที่ใช้ในโรคหัวใจขาดเลือด

ในทางทฤษฎี การขยายหลอดเลือดอาจช่วยเพิ่มเลือดไปเลี้ยงรากผม คล้ายกับ minoxidil แต่นี่เป็นเพียงข้อสันนิษฐาน ยังไม่มีหลักฐานทางคลินิกหรือวรรณกรรมรองรับ ความเชื่อมโยงนี้จึงอาศัยคะแนนจากโมเดล TxGNN เท่านั้น และยังไม่มีการประเมินความคล้ายคลึงกับข้อบ่งใช้เดิมอย่างเป็นระบบ

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ |
|---------|------|------|-----------|

## ข้อพิจารณาด้านความปลอดภัย

เอกสารกำกับยาในไทยไม่มีข้อมูลคำเตือนและข้อห้ามใช้ให้ตรวจสอบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยาฉบับล่าสุด

- **ปฏิกิริยาระหว่างยา**: พบรายการปฏิกิริยาระหว่างยารวม 100 รายการ ที่ควรทราบเป็นพิเศษ:
  - ระดับปานกลาง: bupropion, morphine, opium, dronabinol, nabilone, sapropterin, rosiglitazone และยากลุ่ม SGLT2 inhibitors (canagliflozin, dapagliflozin, empagliflozin, ertugliflozin)
  - ระดับเล็กน้อย: omeprazole
- **โรคหรือภาวะที่กราฟความรู้ของโมเดลระบุว่าอาจเป็นข้อห้าม** (ไม่ใช่ข้อมูลจากเอกสารกำกับยา ต้องตรวจสอบกับฉลากจริง): ความดันโลหิตต่ำ, ภาวะกล้ามเนื้อหัวใจหนาตัด (hypertrophic cardiomyopathy), กล้ามเนื้อหัวใจตาย, โรคหลอดเลือดสมองและเลือดออกในสมอง, ภาวะความดันในกะโหลกศีรษะสูง, โรคโลหิตจาง, ภาวะต่อมไทรอยด์เป็นพิษ/Graves disease

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ผมร่วงมีเพียงคะแนนทำนายจากโมเดล ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับ (ระดับ L5) และทะเบียนยาในไทยถูกยกเลิกทั้งหมดแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ค้นหาหลักฐานก่อนคลินิกหรือการศึกษากลไกที่เชื่อมไนตริกออกไซด์/การไหลเวียนเลือดรอบรากผมกับผมร่วง
- เก็บข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลยา
- ดาวน์โหลดและตรวจสอบเอกสารกำกับยาจาก อย. ไทย เพื่อยืนยันคำเตือนและข้อห้ามใช้
- ประเมินความเป็นไปได้ของรูปแบบยาที่เหมาะกับผมร่วง (ปัจจุบันมีเฉพาะยาเม็ดชนิดรับประทาน) และความเสี่ยงความดันโลหิตต่ำจากการใช้ยาทั้งระบบ
- พิจารณาข้อบ่งใช้อื่นที่ TxGNN ทำนายและมีหลักฐานมากกว่า เช่น โรคหลอดเลือด (vascular disease, ระดับ L2 มีการทดลอง Phase 3 ที่เสร็จสิ้นในแผลเบาหวานที่เท้า) และความดันในหลอดเลือดปอดสูง (ระดับ L3) แต่ข้อบ่งใช้เหล่านี้ไม่ได้อยู่ในอันดับแรกของรายงานฉบับนี้
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
