# Brimonidine: จากต้อหินสู่เยื่อบุตาอักเสบชนิดปุ่ม (Papillary Conjunctivitis)

## สรุปสั้นๆ

Brimonidine เป็นยาหยอดตาที่เดิมใช้รักษา **ต้อหิน** โมเดล TxGNN คาดการณ์ว่าอาจเกี่ยวข้องกับ **เยื่อบุตาอักเสบชนิดปุ่ม (Papillary Conjunctivitis)** แต่วรรณกรรมที่พบชี้ว่าเป็น **ผลข้างเคียงจากยา** ไม่ใช่ผลการรักษา ปัจจุบัน **ไม่มีการทดลองทางคลินิก** และมี **วรรณกรรม 3 ฉบับ** (รายงานผู้ป่วยและการศึกษาตามรุ่น) ที่ไม่สนับสนุนการนำมาใช้รักษา

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ต้อหิน |
| ข้อบ่งใช้ใหม่ที่ทำนาย | เยื่อบุตาอักเสบชนิดปุ่ม (Papillary Conjunctivitis) |
| คะแนนการทำนาย TxGNN | 98.49% |
| ระดับหลักฐาน | L4 |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกแล้วทั้งหมด (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Brimonidine เป็นยากลุ่ม alpha-2 adrenergic agonist ที่ลดความดันตาโดยลดการสร้างน้ำในลูกตาและเพิ่มการระบายน้ำทางเส้นทาง uveoscleral ซึ่งใช้ได้ผลในต้อหิน

อย่างไรก็ตาม คะแนนทำนายที่สูงของ TxGNN น่าจะสะท้อนความสัมพันธ์ระหว่างยากับโรคในทิศทาง **ผลไม่พึงประสงค์** เพราะวรรณกรรมรายงานว่า Brimonidine ทำให้เกิดเยื่อบุตาอักเสบจากภูมิแพ้ ชนิดตุ่มหรือปุ่ม ซึ่งเป็นผลข้างเคียงที่ทราบกันดี ไม่ใช่ผลการรักษา จึงไม่สนับสนุนการนำมาใช้รักษาโรคนี้

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้เชิงความรู้ (ได้จากฐานความรู้ TxGNN ไม่ใช่ข้อความในเอกสารกำกับยา)**: ยาถูกระบุว่าสัมพันธ์กับข้อห้ามใช้ในผู้ป่วยกลุ่มต่อไปนี้
  - ระบบประสาทอัตโนมัติและความดันโลหิต: multiple system atrophy, postural orthostatic tachycardia syndrome, orthostatic hypotension
  - จิตเวช: anxiety disorder, neurotic disorder, dysthymic disorder
  - เมตาบอลิก: เบาหวาน, diabetic ketoacidosis, hypoglycemia, hyperthyroidism, Graves disease, thyrotoxicosis
  - กล้ามเนื้อและระบบประสาท: myasthenia gravis (รวมชนิดเริ่มในผู้ใหญ่), neuromuscular junction disease
  - หัวใจ หลอดเลือด และปอด: atrioventricular block, cerebrovascular disorder, pulmonary emphysema, bronchial disease, Raynaud disease, thromboangiitis obliterans
  - อื่นๆ: anaphylaxis
- **ปฏิกิริยาระหว่างยา**: พบรายการที่เป็นไปได้ 100 รายการ ส่วนใหญ่ยังไม่ระบุระดับความรุนแรง ตัวอย่างเช่น Calcitriol, Phentermine, Pantoprazole, Glimepiride, Metformin, Omeprazole, Atropine, Prednisone, Simvastatin และ Hydrocortisone
- **ผลไม่พึงประสงค์ที่พบในวรรณกรรม**: เยื่อบุตาอักเสบจากภูมิแพ้ ยูเวียอักเสบส่วนหน้า และปฏิกิริยาที่ผิวหนัง (เช่น ลักษณะคล้าย lichen planus)

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของไทยยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- หลักฐานที่มีชี้ว่าความสัมพันธ์กับเยื่อบุตาอักเสบชนิดปุ่มเป็นผลข้างเคียงจากยา ไม่ใช่ประโยชน์ในการรักษา และไม่มีการทดลองทางคลินิกรองรับ
- ทะเบียนยาในไทยถูกยกเลิกแล้ว และยังขาดข้อมูลความปลอดภัยจากเอกสารกำกับยา

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและวิเคราะห์เอกสารกำกับยาจากเว็บไซต์ อย.ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้
- เพิ่มข้อมูลกลไกการออกฤทธิ์จาก DrugBank
- หาหลักฐานว่า Brimonidine มีผลรักษาโรคนี้จริง ไม่ใช่เพียงทำให้เกิดโรค
- พิจารณาสถานะทะเบียนที่ถูกยกเลิก หากจะนำยากลับมาวางจำหน่ายหรือขอข้อบ่งใช้ใหม่

**ข้อสังเกตอื่น:** ข้อบ่งใช้ที่ทำนายอันดับ 2 (primary hereditary glaucoma) ซ้อนทับกับข้อบ่งใช้เดิมและไม่มีหลักฐานเฉพาะ ส่วนอันดับ 3, 8, 9 และ 10 (กลุ่มโรค lichen) น่าจะมาจากความสัมพันธ์ด้านผลไม่พึงประสงค์เช่นกัน ทุกรายการจึงยังเป็น Hold
