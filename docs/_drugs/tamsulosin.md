# Tamsulosin: จากต่อมลูกหมากโตสู่กลุ่มอาการขนดกแต่กำเนิดแบบ Ambras (Ambras type hypertrichosis universalis congenita)

## สรุปสั้นๆ

Tamsulosin เป็นยากลุ่มต้านตัวรับแอลฟา-1 ซึ่งเดิมใช้รักษาภาวะต่อมลูกหมากโต โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **Ambras type hypertrichosis universalis congenita** ด้วยคะแนนสูงมาก แต่คะแนนนี้มาจากความใกล้เคียงกันในกราฟความรู้เท่านั้น ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมที่สนับสนุนข้อบ่งใช้นี้โดยตรง** จึงจัดเป็นหลักฐานระดับต่ำสุด

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ต่อมลูกหมากโต |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Ambras type hypertrichosis universalis congenita |
| คะแนนการทำนาย TxGNN | 99.996% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Tamsulosin เป็นยาต้านตัวรับแอลฟา-1A/1D แอดรีเนอร์จิก ใช้บรรเทาอาการทางเดินปัสสาวะจากต่อมลูกหมากโต

ยังไม่พบความเชื่อมโยงเชิงกลไกที่ชัดเจนระหว่างยานี้กับ Ambras syndrome ซึ่งเป็นโรคทางพันธุกรรม (เกี่ยวข้องกับบริเวณโครโมโซม 8q22) การปิดกั้นตัวรับแอลฟา-1 ไม่มีบทบาทที่ทราบในการควบคุมการเจริญของเส้นผมหรือขน ดังนั้นการคาดการณ์นี้จึงมาจากความใกล้เคียงกันในกราฟความรู้เป็นหลัก และยังไม่มีข้อมูลทางกลไกหรือทางคลินิกรองรับ

การคาดการณ์อื่นๆ ที่คะแนนสูงเช่นกัน (เช่น ภาวะขนดก ผมร่วง ผมร่วงเป็นหย่อม) ก็อยู่ในสถานการณ์เดียวกัน คือไม่มีกลไกหรือหลักฐานทางคลินิกสนับสนุน

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้องกับข้อบ่งใช้ที่ทำนายอันดับ 1 โดยตรง

## ข้อมูลการวางจำหน่ายในประเทศไทย

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ |
|---------|------|------|-----------|
| 1A 131/67 (สถานะ: ยกเลิก) | Tamsulosin | แคปซูล | ต่อมลูกหมากโต |

## ข้อพิจารณาด้านความปลอดภัย

- **โรคหรือภาวะที่มีข้อห้ามหรือต้องระวัง (จากกราฟความรู้ ไม่ใช่ข้อความในเอกสารกำกับยา)**: multiple system atrophy, postural orthostatic tachycardia syndrome, ความดันโลหิตต่ำเมื่อเปลี่ยนท่า (orthostatic hypotension), โรคตับ, โรคถุงน้ำดี, ภาวะอวัยวะเพศแข็งค้าง (priapism), กลุ่มอาการม่านตาหย่อนระหว่างผ่าตัด (intraoperative floppy iris syndrome)
- **ปฏิกิริยาระหว่างยา**: ตรวจพบ 100 รายการ ที่เด่นคือ
  - ระดับรุนแรง (Major): **Clarithromycin**
  - ระดับปานกลาง (Moderate) เช่น Bupropion, Aprepitant, Morphine, Cimetidine, Canagliflozin, Dapagliflozin, Empagliflozin, Miconazole, Clotrimazole, Fenfluramine

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทยยังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล ไม่มีการทดลองทางคลินิก ไม่มีวรรณกรรมโดยตรง และไม่มีกลไกที่สมเหตุสมผล (ระดับหลักฐาน L5) นอกจากนี้ใบอนุญาตในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์ที่ครบถ้วนจาก DrugBank และการวิเคราะห์ความเชื่อมโยงเชิงกลไกกับโรคเป้าหมาย
- เอกสารกำกับยาจาก อย. ไทย เพื่อประเมินคำเตือนและข้อห้ามใช้ก่อนคัดกรองความปลอดภัย
- หลักฐานก่อนคลินิกหรือการศึกษากลไกที่แสดงว่าการปิดกั้นตัวรับแอลฟา-1 มีผลต่อโรคเป้าหมาย
- ทบทวนความจำเป็นทางคลินิก เนื่องจากโรคเป้าหมายเป็นโรคพันธุกรรมหายาก ซึ่งยาที่ออกฤทธิ์บรรเทาอาการไม่น่าจะแก้ไขสาเหตุได้
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
