# Terbinafine: จากเชื้อราผิวหนังสู่ภาวะหนอนแมลงวันชอนผิวหนังแบบฝี (Furuncular Myiasis)

## สรุปสั้นๆ

Terbinafine เป็นยาต้านเชื้อรา เดิมใช้รักษาเชื้อราผิวหนัง
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ภาวะหนอนแมลงวันชอนผิวหนังแบบฝี (Furuncular Myiasis)**
แต่หลักฐานอ่อนมาก คือ **ไม่มีการทดลองทางคลินิก** และมี **วรรณกรรมเพียง 1 ฉบับ** ซึ่งเป็นรายงานผู้ป่วยด้านการวินิจฉัย ไม่ได้แสดงว่ายามีประสิทธิผล

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลยา อย่างไรก็ตาม จากความรู้ที่ทราบ Terbinafine ยับยั้งเอนไซม์ squalene epoxidase ของเชื้อรา ทำให้ ergosterol ลดลงและ squalene สะสมจนเชื้อราตาย จึงมีฤทธิ์ฆ่าเชื้อราในกลุ่มเชื้อราผิวหนัง ซึ่งเป็นข้อบ่งใช้เดิม

กลไกนี้จำเพาะต่อเชื้อรา และยังไม่มีหลักฐานว่า Terbinafine ออกฤทธิ์ต่อตัวอ่อนของแมลงวันที่ทำให้เกิดภาวะ myiasis ดังนั้นในเชิงกลไก **การคาดการณ์นี้ยังไม่มีเหตุผลรองรับที่ชัดเจน**

วรรณกรรมที่พบเพียงฉบับเดียวมีเพียงการเอ่ยถึง Terbinafine ว่าเป็นยาที่ผู้ป่วยเคยได้รับโดยไม่ได้ผล ก่อนที่จะวินิจฉัยได้ว่าเป็น myiasis ความเชื่อมโยงของโมเดลจึงน่าจะมาจากการที่ยาและโรคปรากฏในเอกสารเดียวกัน ไม่ใช่จากหลักฐานว่ายารักษาโรคนี้ได้

## ข้อพิจารณาด้านความปลอดภัย

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยายังไม่ครบ กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

- **ปฏิกิริยาระหว่างยา**: พบรายการที่บันทึกไว้ทั้งหมด 100 รายการ รายการสำคัญได้แก่
  - ระดับรุนแรง (Major): Eliglustat
  - ระดับปานกลาง (Moderate): Morphine, Naltrexone, Ondansetron, Dexfenfluramine, Fenfluramine
  - ระดับเล็กน้อย (Minor): Cimetidine
- **โรคที่ฐานความรู้ชี้ว่าอาจเป็นข้อห้ามใช้**: โรคไต, โรคตับ, โรคถุงน้ำดี, โรคเอสแอลอี (SLE) รวมถึงชนิดในเด็ก, ภาวะหนองในท่อไต (pyoureter) และการใช้สารเสพติด/การติดสาร ข้อมูลนี้มาจากฐานความรู้ของโมเดล ไม่ใช่ข้อความในเอกสารกำกับยา จึงควรตรวจสอบกับเอกสารกำกับยาอีกครั้ง

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- มีเพียงคะแนนจากโมเดลและรายงานผู้ป่วยหนึ่งฉบับที่ไม่ได้แสดงประสิทธิผล ขณะที่กลไกของยาจำเพาะต่อเชื้อราและไม่น่าจะออกฤทธิ์ต่อตัวอ่อนแมลงวัน
- ทะเบียนยาในไทยถูกยกเลิกทั้งหมด และข้อมูลความปลอดภัยจากเอกสารกำกับยายังไม่ครบ

**หากต้องการดำเนินการต่อต้อง:**
- หลักฐานก่อนคลินิก เช่น การทดสอบฤทธิ์ต่อตัวอ่อนแมลงวัน เพื่อยืนยันว่ามีกลไกที่เป็นไปได้
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- เอกสารกำกับยาจาก อย. เพื่อประเมินคำเตือนและข้อห้ามใช้
- ตรวจสอบสถานะทะเบียนยาและแหล่งผลิตที่ยังจำหน่ายในไทย

**ข้อสังเกตเพิ่มเติม:** ในรายการทำนายอื่น เช่น เชื้อราที่มือ (tinea manuum) และโรคเชื้อราชั้นตื้น (superficial mycosis) มีหลักฐานระดับ L3 และอยู่ใกล้ข้อบ่งใช้เดิมของยามากกว่า จึงอาจเป็นแนวทางที่ควรพิจารณาก่อน
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
