# Latanoprost: จากต้อหินและความดันในตาสูงสู่ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม

## สรุปสั้นๆ

Latanoprost เป็นยาหยอดตาที่เดิมใช้รักษาต้อหินและความดันในตาสูง โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม (Primary Hereditary Glaucoma)** ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรม** สำหรับข้อบ่งใช้นี้ในข้อมูลที่รวบรวมสำหรับรายงาน การสนับสนุนจึงมาจากกลไกการออกฤทธิ์และข้อบ่งใช้เดิมเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ต้อหิน, ความดันในตาสูง |
| ข้อบ่งใช้ใหม่ที่ทำนาย | ต้อหินปฐมภูมิชนิดถ่ายทอดทางพันธุกรรม (Primary Hereditary Glaucoma) |
| คะแนนการทำนาย TxGNN | 99.88% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ทะเบียนถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ยังใช้ได้) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดจากฐานข้อมูลยา อย่างไรก็ตาม ตามข้อมูลที่ทราบ Latanoprost เป็นอนุพันธ์ของพรอสตาแกลนดิน F2-alpha ซึ่งลดความดันในตาโดยเพิ่มการระบายของเหลวผ่านทางยูเวียสเคลอรัล (uveoscleral outflow)

ต้อหินชนิดถ่ายทอดทางพันธุกรรมมีปัญหาหลักที่ความดันในตาสูงเช่นเดียวกับต้อหินทั่วไป กลไกการลดความดันตาจึงน่าจะใช้ได้ในเชิงทฤษฎี และยานี้ได้รับการยอมรับในการรักษาต้อหินอยู่แล้ว

อย่างไรก็ตาม การคาดการณ์นี้ยังไม่มีการทดลองหรือวรรณกรรมรองรับโดยตรง จึงเป็นเพียงสมมติฐานระดับคำถามวิจัย ข้อบ่งใช้ใหม่นี้ยังใกล้เคียงกับข้อบ่งใช้เดิมมาก จึงอาจไม่ถือเป็นการนำยามาใช้ในโรคใหม่อย่างแท้จริง

## ข้อพิจารณาด้านความปลอดภัย

- **โรคที่ฐานความรู้ระบุว่ามีข้อควรระวัง/ข้อห้าม** (จากกราฟความรู้ TxGNN ไม่ใช่ข้อความในเอกสารกำกับยา): ยูเวียอักเสบ (uveitis), โรคของม่านตา, โรคของซีเลียรีบอดี, panuveitis, จอตาส่วนกลางบวมน้ำ (macular edema), cystoid macular edema, ม่านตาอักเสบ (iritis), เยื่อบุตาอักเสบ (conjunctivitis) รวมถึงชนิดติดต่อเฉียบพลัน
- **ปฏิกิริยาระหว่างยา**: พบรายการที่อาจเกิดปฏิกิริยา 100 รายการ แต่ยังไม่ระบุระดับความรุนแรง ตัวอย่างเช่น Atropine, Triamcinolone, Prednisone, Metformin, Omeprazole, Simvastatin และ Morphine จึงควรตรวจสอบก่อนใช้ร่วมกัน

สำหรับคำเตือนและข้อห้ามใช้จากเอกสารกำกับยา กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- คะแนนจากโมเดลสูง แต่ไม่มีการทดลองทางคลินิกหรือวรรณกรรมรองรับข้อบ่งใช้นี้ ทะเบียนยาในไทยก็ถูกยกเลิกแล้ว และยังไม่มีข้อมูลคำเตือนจากเอกสารกำกับยา

**หากต้องการดำเนินการต่อต้อง:**
- ค้นหาและรวบรวมการทดลองทางคลินิกและวรรณกรรมเกี่ยวกับ Latanoprost ในต้อหินชนิดถ่ายทอดทางพันธุกรรม รวมถึงในผู้ป่วยเด็ก
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- เอกสารกำกับยาฉบับเต็มเพื่อตรวจสอบคำเตือนและข้อห้ามใช้
- ตรวจสอบสถานะทะเบียนยาในไทย เนื่องจากปัจจุบันไม่มีทะเบียนที่ใช้งานได้
- ประเมินความปลอดภัยในผู้ป่วยที่มีภาวะอักเสบของตา (เช่น ยูเวียอักเสบ จอตาบวมน้ำ)
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
