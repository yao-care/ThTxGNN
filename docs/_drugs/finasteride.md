# Finasteride: จากต่อมลูกหมากโตและผมร่วงสู่ภาวะขนดกผิดปกติ (Ambras type hypertrichosis universalis congenita)

## สรุปสั้นๆ

Finasteride เดิมใช้รักษา **ต่อมลูกหมากโตและผมร่วง** โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **Ambras type hypertrichosis universalis congenita** (ภาวะขนดกแต่กำเนิดชนิด Ambras) แต่ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรมที่สนับสนุนข้อบ่งใช้นี้เลย จึงถือเป็นเพียงการทำนายจากโมเดล

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ต่อมลูกหมากโต, ผมร่วง |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Ambras type hypertrichosis universalis congenita |
| คะแนนการทำนาย TxGNN | 99.99% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามความรู้ทั่วไป Finasteride ยับยั้งเอนไซม์ 5-alpha-reductase ชนิดที่ 2 ทำให้ระดับ dihydrotestosterone (DHT) ลดลง จึงใช้ในต่อมลูกหมากโตและผมร่วงแบบพันธุกรรมที่ขึ้นกับแอนโดรเจน

อย่างไรก็ตาม Ambras syndrome เป็นความผิดปกติแต่กำเนิดที่เกิดจากการจัดเรียงโครโมโซมซึ่งกระทบการควบคุมยีน TRPS1 ไม่ได้ขับเคลื่อนด้วยแอนโดรเจนเป็นหลัก ประโยชน์จากการลด DHT จึงเป็นเพียงข้อสันนิษฐาน และการทำนายนี้ไม่มีหลักฐานทางคลินิกรองรับ

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้องกับข้อบ่งใช้ที่ทำนายนี้โดยตรง

> หมายเหตุ: ข้อบ่งใช้อันดับถัดมา คือ ภาวะขนดก (hypertrichosis) มีวรรณกรรมทบทวน 4 ฉบับ แต่เป็นบทความภาพรวมโรคเส้นผมโดยทั่วไป ไม่ใช่หลักฐานเฉพาะของ finasteride และภาวะขนดกมักไม่ขึ้นกับแอนโดรเจน

## ข้อมูลการวางจำหน่ายในประเทศไทย

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ | สถานะ |
|---------|------|------|-----------|------|
| 1A 132/67 | Finasteride | ยาเม็ด | ต่อมลูกหมากโต, ผมร่วง | ยกเลิกแล้ว |

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้ (จากฐานความรู้ TxGNN ไม่ใช่ข้อความในเอกสารกำกับยา)**: โรคตับ และโรคถุงน้ำดี
- **ปฏิกิริยาระหว่างยา**: พบรายการที่อาจมีปฏิกิริยา 100 รายการ แต่ยังไม่ระบุระดับความรุนแรง ตัวอย่าง เช่น calcitriol, doxycycline, clotrimazole, famotidine, acetylsalicylic acid, amoxicillin, bupropion, pantoprazole, glimepiride, metformin, omeprazole, morphine
- **ข้อควรระวังเพิ่มเติม**: ยังไม่มีข้อมูลคำเตือนจากเอกสารกำกับยาไทย ควรตรวจสอบเอกสารกำกับยาก่อนใช้งาน

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล ไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุน และกลไกที่เชื่อมโยงยังเป็นเพียงข้อสันนิษฐาน นอกจากนี้ทะเบียนยาในไทยถูกยกเลิกแล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ดึงข้อมูลกลไกการออกฤทธิ์จาก DrugBank เพิ่มเติม
- รวบรวมคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทย
- ศึกษาก่อนคลินิกหรือกลไกที่เชื่อมระหว่างการลด DHT กับพยาธิกำเนิดของ Ambras syndrome (ยีน TRPS1)
- พิจารณาข้อบ่งใช้อื่นที่มีหลักฐานทางอ้อมมากกว่า เช่น prostate calculus (L4) ซึ่งเกี่ยวข้องกับการลดการคั่งค้างของปัสสาวะจากต่อมลูกหมากโต โดยเป็นแนวทางเชิงงานวิจัยเท่านั้น
- ตรวจสอบสถานะการขึ้นทะเบียนใหม่หากต้องการนำยากลับมาใช้ในประเทศไทย

จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
