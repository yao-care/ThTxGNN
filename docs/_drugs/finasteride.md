## Finasteride: ยาต้านเอนไซม์ 5-alpha-reductase ชนิดที่ II → ภาวะขนดกทั่วตัวแต่กำเนิดชนิดแอมบราส (Ambras type hypertrichosis universalis congenita)
{: .text-alpha }

## สรุปสั้นๆ

Finasteride เป็นยากินที่ยับยั้งเอนไซม์ 5-alpha-reductase ชนิดที่ II ทำให้ระดับฮอร์โมนไดไฮโดรเทสโทสเตอโรน (DHT) ลดลง
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **ภาวะขนดกทั่วตัวแต่กำเนิดชนิดแอมบราส (Ambras type hypertrichosis universalis congenita)**
ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกหรือวรรณกรรม** ที่ศึกษาโรคนี้โดยตรง จึงเป็นเพียงการทำนายจากโมเดล

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมไว้ แต่ตามความรู้ทางเภสัชวิทยา Finasteride ยับยั้งเอนไซม์ 5-alpha-reductase ชนิดที่ II และลดระดับ DHT ซึ่งเกี่ยวข้องกับการทำงานของรูขุมขนที่ขึ้นกับฮอร์โมนแอนโดรเจน

อย่างไรก็ตาม โรคแอมบราสเป็นความผิดปกติแต่กำเนิดที่เกิดจากการจัดเรียงโครโมโซมซึ่งกระทบการควบคุมยีน TRPS1 จึงยังไม่ชัดเจนว่าการลดแอนโดรเจนจะให้ประโยชน์ ความเชื่อมโยงนี้เป็นเพียงข้อสันนิษฐาน และคะแนนสูงของโมเดลไม่ได้เป็นหลักฐานทางคลินิก

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ปฏิกิริยาระหว่างยา**: พบรายการปฏิกิริยาระหว่างยา 100 รายการ ยังไม่ระบุระดับความรุนแรง ตัวอย่างเช่น calcitriol, doxycycline, clotrimazole, dolasetron, dicyclomine, famotidine, acetylsalicylic acid, bupropion, metformin และ omeprazole

กรุณาดูคำเตือนและข้อห้ามใช้ในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล ไม่มีการศึกษาที่ศึกษาโรคนี้โดยตรง และกลไกผ่านแอนโดรเจนยังเป็นเพียงข้อสันนิษฐาน

**หากต้องการดำเนินการต่อต้อง:**
- ทบทวนวรรณกรรมเชิงลึกและกลไกของโรคแอมบราสเทียบกับเส้นทาง DHT
- ศึกษาก่อนคลินิกหรือรายงานผู้ป่วยที่ใช้ Finasteride ในภาวะขนดกแต่กำเนิด
- ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย.
- ประเมินความปลอดภัยรวมถึงผลต่อตับและถุงน้ำดีก่อนพิจารณาใช้
