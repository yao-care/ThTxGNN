## Loperamide: จากท้องเสียสู่เยื่อบุตาอักเสบติดต่อเฉียบพลัน
{: .text-alpha }

## สรุปสั้นๆ

Loperamide เดิมใช้รักษาอาการท้องเสีย โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **เยื่อบุตาอักเสบติดต่อเฉียบพลัน (acute contagious conjunctivitis)** แต่ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกและวรรณกรรมสนับสนุน** ถือเป็นการทำนายจากโมเดลเพียงอย่างเดียว

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | ท้องเสีย |
| ข้อบ่งใช้ใหม่ที่ทำนาย | เยื่อบุตาอักเสบติดต่อเฉียบพลัน (acute contagious conjunctivitis) |
| คะแนนการทำนาย TxGNN | 0.9997 |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | วางจำหน่าย (ทะเบียนที่ยังมีผล 31 จาก 216 รายการ) |
| จำนวนทะเบียนตำรับยา | 216 รายการ (ยังมีผล 31) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Loperamide เป็นยากระตุ้นตัวรับ mu-opioid ที่ออกฤทธิ์เป็นหลักที่เส้นประสาทในผนังลำไส้ ช่วยลดการเคลื่อนไหวและการหลั่งของลำไส้ จึงมีประสิทธิผลในการรักษาท้องเสีย

ไม่พบกลไกที่สมเหตุสมผลที่เชื่อมยานี้กับการอักเสบติดเชื้อของเยื่อบุตา คะแนนสูงของโมเดล TxGNN (deep learning) น่าจะสะท้อนความคล้ายคลึงระหว่างโรคที่เกี่ยวข้องกันซึ่งโมเดลเรียนรู้มา ไม่ใช่หลักฐานทางชีวภาพหรือความเชื่อมโยงทางเภสัชวิทยาจริง ผลทำนายอันดับต้นๆ ส่วนใหญ่ (เช่น conjunctivitis, pseudomembranous conjunctivitis, parasitic conjunctivitis) เป็นโรคตากลุ่มเดียวกันและมีข้อจำกัดเดียวกัน

ข้อบ่งใช้อื่นในรายการทำนายที่มีวรรณกรรมบ้าง (amebic dysentery, gastroduodenitis) ชี้ไปทาง **สัญญาณอันตราย** ไม่ใช่ประโยชน์ในการรักษา

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **โรคหรือภาวะที่อาจเป็นข้อห้ามใช้ (จากกราฟความรู้ ไม่ใช่ข้อความในเอกสารกำกับยา)**: โรคตับ, โรคถุงน้ำดี, ลำไส้อัมพาต (paralytic ileus), ลำไส้อุดตัน, familial visceral myopathy, โรคบิด, โรคท้องเสียติดเชื้อ และโรคติดเชื้อในลำไส้
- **ปฏิกิริยาระหว่างยา**: พบรายการจากการสืบค้น 100 รายการ ตัวอย่างระดับ **รุนแรง (Major)** ได้แก่ Abiraterone, Ranitidine, Fosamprenavir, Gemfibrozil ส่วนระดับปานกลาง (Moderate) เช่น Codeine, Tramadol, Dihydrocodeine, Chlorpheniramine, Cetirizine, Salbutamol และเอทานอล
- **สัญญาณความปลอดภัยจากวรรณกรรมในข้อบ่งใช้อื่น**: มีรายงานผู้ป่วยภาวะ amoebic colitis รุนแรงหลังใช้ loperamide (อาจเกิด toxic megacolon) และรายงานการกดการหายใจในผู้ป่วยที่มีการอักเสบรุนแรงของทางเดินอาหาร

คำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทยยังไม่ได้รับการรวบรวม กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล ไม่มีการทดลองทางคลินิก ไม่มีวรรณกรรม และไม่พบกลไกที่สมเหตุสมผล และข้อบ่งใช้อื่นที่มีวรรณกรรมชี้ไปทางความเสี่ยงมากกว่าประโยชน์

**หากต้องการดำเนินการต่อต้อง:**
- ข้อมูลกลไกการออกฤทธิ์ (MOA) จาก DrugBank
- เอกสารกำกับยาของ อย. ไทยเพื่อตรวจสอบคำเตือนและข้อห้ามใช้
- หลักฐานก่อนคลินิกหรือกลไกที่เชื่อมยากับการอักเสบของเยื่อบุตา
- การประเมินความเป็นไปได้ของรูปแบบยาและช่องทางให้ยา (ปัจจุบันมีเฉพาะยารับประทานชนิดเม็ด ซึ่งอาจไม่เหมาะกับโรคตา)
