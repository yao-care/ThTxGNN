# Tretinoin: จากสิวสู่ภาวะข้อรูมาตอยด์ชนิดมีปุ่มใต้ผิวหนัง (Rheumatoid Nodulosis)

## สรุปสั้นๆ

Tretinoin เป็นยาทาภายนอกในรูปแบบครีม ซึ่งเดิมได้รับอนุญาตในประเทศไทยสำหรับรักษา**สิว**
โมเดล TxGNN คาดการณ์ว่ายานี้อาจมีผลต่อ **Rheumatoid Nodulosis** ซึ่งเป็นอันดับแรกของรายการที่ทำนาย
อย่างไรก็ตาม ปัจจุบัน**ยังไม่มีการทดลองทางคลินิกและไม่มีวรรณกรรมที่เกี่ยวข้อง**สนับสนุนข้อบ่งใช้นี้ จึงเป็นเพียงการทำนายจากโมเดลเท่านั้น

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | สิว |
| ข้อบ่งใช้ใหม่ที่ทำนาย | Rheumatoid Nodulosis |
| คะแนนการทำนาย TxGNN | 99.84% |
| ระดับหลักฐาน | L5 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีใบอนุญาตที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดของ Tretinoin ในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามข้อมูลที่ทราบ Tretinoin เป็นสารกลุ่มเรติโนอิด (กรดเรติโนอิก) ที่ออกฤทธิ์ผ่านตัวรับกรดเรติโนอิก (RAR) ประสิทธิผลในการรักษาสิวได้รับการพิสูจน์แล้ว และในเชิงกลไกอาจเกี่ยวข้องกับฤทธิ์ต้านการอักเสบและการปรับภูมิคุ้มกัน

ในเชิงสมมติฐาน การส่งสัญญาณของกรดเรติโนอิกอาจปรับสมดุลของเซลล์ T (Th17/Treg) ซึ่งเกี่ยวข้องกับโรคภูมิต้านตนเองกลุ่มข้ออักเสบ อย่างไรก็ตาม **ยังไม่มีหลักฐานโดยตรง**ที่เชื่อม Tretinoin กับ Rheumatoid Nodulosis ความเชื่อมโยงนี้จึงเป็นการอนุมานเชิงกลไกเท่านั้น

นอกจากนี้ ยังมีข้อสังเกตว่ารายการที่โมเดลทำนายส่วนใหญ่เป็นโรคข้ออักเสบในเด็กและโรคกระดูก (เช่น juvenile idiopathic arthritis, osteoarthritis) ซึ่งทั้งหมดยังอยู่ที่ระดับหลักฐาน L5 เช่นกัน

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## หลักฐานจากวรรณกรรม

ปัจจุบันยังไม่มีวรรณกรรมที่เกี่ยวข้อง

## ข้อมูลการวางจำหน่ายในประเทศไทย

| เลขทะเบียนยา | ชื่อการค้า | รูปแบบยา | ข้อบ่งใช้ที่ได้รับอนุมัติ |
|---------|------|------|-----------|
| 1A 135/67 (สถานะ: ยกเลิก) | Tretinoin | ครีม | สิว |

## ความเป็นพิษต่อเซลล์

ข้อมูลที่รวบรวมไม่ได้จัดว่า Tretinoin ในรูปแบบครีมที่ได้รับอนุญาตในไทยเป็นยาต้านเนื้องอก (ข้อบ่งใช้เดิมคือสิว) จึงไม่แสดงส่วนนี้

## ข้อพิจารณาด้านความปลอดภัย

**ปฏิกิริยาระหว่างยา** (พบทั้งหมด 100 รายการ แสดงรายการสำคัญ)

| ระดับ | ยาที่มีปฏิกิริยา |
|------|------|
| รุนแรง (Major) | Doxycycline, Tetracycline, Minocycline, Vitamin A |
| ปานกลาง (Moderate) | Aprepitant, Clarithromycin, Naltrexone |
| เล็กน้อย (Minor) | Levofloxacin |

**โรคหรือภาวะที่อาจเป็นข้อห้ามใช้ (จากฐานความรู้ TxGNN ไม่ใช่ข้อความในเอกสารกำกับยา)**
- ผิวไหม้แดด (sunburn)
- โรคตับ โรคไต ตับอ่อนอักเสบ โรคถุงน้ำดี
- หัวใจล้มเหลวคั่งน้ำ
- โรคเบาหวานและภาวะคีโตแอซิโดซิสจากเบาหวาน
- โรคลำไส้อักเสบเรื้อรัง (Crohn, IBD)
- ภาวะกระดูกพรุน
- ผิวหนังอักเสบภูมิแพ้ (atopic eczema)
- โรคทางจิตเวช (จิตเภท ความวิตกกังวล ฯลฯ)
- ภาวะต่อมหมวกไตบกพร่อง (Addison)
- ภาวะมะเร็งต่อมน้ำเหลืองชนิดเซลล์ T ที่ผิวหนัง (เช่น mycosis fungoides)

ข้อมูลข้างต้นเป็นเพียงความสัมพันธ์จากฐานความรู้ ไม่ได้ยืนยันจากเอกสารกำกับยา โดยเฉพาะข้อมูลของรูปแบบยาทาภายนอกอาจต่างจากยารับประทาน กรุณาดูคำเตือนและข้อห้ามใช้ในเอกสารกำกับยา

นอกจากนี้ ยังมีข้อกังวลเชิงทฤษฎีว่าเรติโนอิดอาจมีผลก่อวิรูปต่อกระดูกและโครงสร้างในทารกในครรภ์ ซึ่งควรพิจารณาในโรคกลุ่มกระดูกที่ทำนายไว้

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- ข้อบ่งใช้ที่ทำนายมีเพียงคะแนนจากโมเดล ไม่มีการทดลองทางคลินิกหรือวรรณกรรมสนับสนุน (L5) นอกจากนี้ใบอนุญาตเดียวในไทยถูกยกเลิกแล้ว และข้อมูลความปลอดภัยจากเอกสารกำกับยายังไม่ครบ

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดเอกสารกำกับยาจากเว็บไซต์ อย. เพื่อยืนยันคำเตือนและข้อห้ามใช้
- เติมข้อมูลกลไกการออกฤทธิ์ (MOA) จาก DrugBank
- ทบทวนวรรณกรรมเพื่อหาหลักฐานก่อนคลินิกหรือการศึกษากลไกที่เชื่อม Tretinoin กับ Rheumatoid Nodulosis
- ประเมินความเข้ากันได้ของช่องทางการให้ยา เนื่องจากยาที่เคยได้รับอนุญาตเป็นครีมทาภายนอก แต่โรคที่ทำนายเป็นโรคระบบ/ข้อ ซึ่งอาจต้องใช้รูปแบบยาอื่น
- พิจารณาสถานะใบอนุญาตที่ยกเลิกแล้ว หากต้องการนำกลับมาจำหน่ายหรือพัฒนาต่อ
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
