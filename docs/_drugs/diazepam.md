# Diazepam: จากวิตกกังวล ชัก และกล้ามเนื้อเกร็ง สู่โรคนอนไม่หลับ

## สรุปสั้นๆ

Diazepam เป็นยากลุ่มเบนโซไดอะซีพีน เดิมใช้รักษาอาการวิตกกังวล ชัก และกล้ามเนื้อเกร็ง
โมเดล TxGNN คาดการณ์ว่าอาจมีผลต่อ **โรคนอนไม่หลับ (Insomnia)**
ปัจจุบัน **ยังไม่มีการทดลองทางคลินิกที่ลงทะเบียน** และมี **วรรณกรรม 16 ฉบับ** ซึ่งเป็นหลักฐานทางอ้อมเป็นส่วนใหญ่ (บทความทบทวน งานในสัตว์ทดลอง ข้อมูลเชิงสังเกต) ไม่มีการศึกษาเฉพาะของ diazepam ในข้อบ่งใช้นี้

## ภาพรวมฉบับย่อ

| รายการ | เนื้อหา |
|------|------|
| ข้อบ่งใช้เดิม | วิตกกังวล, ชัก, กล้ามเนื้อเกร็ง |
| ข้อบ่งใช้ใหม่ที่ทำนาย | โรคนอนไม่หลับ (Insomnia) |
| คะแนนการทำนาย TxGNN | 99.99% |
| ระดับหลักฐาน | L4 |
| สถานะการวางจำหน่ายในไทย | ใบอนุญาตถูกยกเลิกทั้งหมด (ไม่มีทะเบียนที่ใช้งานอยู่) |
| จำนวนใบอนุญาต | 1 รายการ (ยกเลิกแล้ว) |
| คำแนะนำในการตัดสินใจ | Hold |

## ทำไมการคาดการณ์นี้จึงสมเหตุสมผล?

ปัจจุบันยังขาดข้อมูลกลไกการออกฤทธิ์โดยละเอียดในข้อมูลที่รวบรวมสำหรับรายงานนี้ ตามความรู้ทางเภสัชวิทยาทั่วไป diazepam เป็นตัวปรับเพิ่มฤทธิ์ (positive allosteric modulator) ของตัวรับ GABA-A ซึ่งทำให้เกิดฤทธิ์สงบประสาทและชวนหลับ

ฤทธิ์ดังกล่าวเชื่อมโยงกับข้อบ่งใช้เดิมคือวิตกกังวลและกล้ามเนื้อเกร็ง และอาจช่วยลดเวลาที่ใช้ในการเริ่มหลับได้ ซึ่งเป็นเหตุผลที่โมเดลทำนายโรคนอนไม่หลับ ซึ่งมักพบร่วมกับความวิตกกังวล

อย่างไรก็ตาม วรรณกรรมที่พบเป็นหลักฐานทางอ้อม ไม่มีการทดลองเฉพาะ diazepam ในโรคนอนไม่หลับ นอกจากนี้ยามีผลเปลี่ยนโครงสร้างการนอนและมีความเสี่ยงการติดยา

## หลักฐานจากการทดลองทางคลินิก

ปัจจุบันยังไม่มีการลงทะเบียนการทดลองทางคลินิกที่เกี่ยวข้อง

## ข้อพิจารณาด้านความปลอดภัย

- **ข้อห้ามใช้/โรคที่ต้องระวังจากฐานความรู้ TxGNN (ไม่ใช่ข้อความจากเอกสารกำกับยา):** ตับวายและโรคตับ โรคถุงน้ำดี ต้อหินทั้งชนิดมุมเปิดและมุมปิด ภาวะหยุดหายใจขณะหลับ ภาวะหายใจล้มเหลว โรคปอด myasthenia gravis และโรคของรอยต่อประสาทกล้ามเนื้อ ผู้มีประวัติติดสารเสพติด รวมถึงโรควิตกกังวล
- **ปฏิกิริยาระหว่างยา** (พบทั้งหมด 100 รายการ แสดงรายการสำคัญ):
  - ระดับ **Major**: morphine
  - ระดับ **Moderate**: bupropion, aprepitant, omeprazole, esomeprazole, cimetidine, clarithromycin, cisapride, clotrimazole, miconazole, dronabinol, metoclopramide
  - ระดับ **Minor**: dexamethasone, betamethasone และยาลดกรดกลุ่มแมกนีเซียม/อะลูมิเนียม/แคลเซียม
- **ข้อสังเกตจากวรรณกรรม:** การใช้ระยะยาวสัมพันธ์กับการพึ่งพายา ความจำเสื่อม การหกล้ม และความเสี่ยงมะเร็งเต้านมที่เพิ่มขึ้น

ข้อมูลคำเตือนและข้อห้ามใช้จากเอกสารกำกับยาของ อย. ไทยยังไม่ครบถ้วน กรุณาดูข้อมูลความปลอดภัยในเอกสารกำกับยา

## สรุปและขั้นตอนถัดไป

**การตัดสินใจ: Hold**

**เหตุผล:**
- โรคนอนไม่หลับมีหลักฐานระดับ L4 เท่านั้น ไม่มีการทดลองทางคลินิก และวรรณกรรมเป็นหลักฐานทางอ้อม ขณะที่ใบอนุญาตในไทยถูกยกเลิกแล้วและยังขาดข้อมูลความปลอดภัยจากเอกสารกำกับยา
- ความเสี่ยงการติดยา การเปลี่ยนแปลงโครงสร้างการนอน และปฏิกิริยาระหว่างยาที่สำคัญ ทำให้สัดส่วนประโยชน์ต่อความเสี่ยงยังไม่เอื้อ และมียานอนหลับที่ออกแบบมาโดยเฉพาะอยู่แล้ว

**หากต้องการดำเนินการต่อต้อง:**
- ดาวน์โหลดและวิเคราะห์เอกสารกำกับยาจากเว็บไซต์ อย. ไทย เพื่อให้ได้คำเตือนและข้อห้ามใช้ที่ครบถ้วน (ช่องว่างข้อมูลระดับ Blocking)
- ข้อมูลกลไกการออกฤทธิ์โดยละเอียดจาก DrugBank
- หลักฐานจากการทดลองแบบสุ่มที่มีกลุ่มควบคุมซึ่งศึกษา diazepam โดยตรงในโรคนอนไม่หลับ
- ตรวจสอบสถานะการขึ้นทะเบียนใหม่ในประเทศไทย เนื่องจากใบอนุญาตเดียวที่มีถูกยกเลิกแล้ว

**หมายเหตุเกี่ยวกับข้อบ่งใช้อื่นที่ทำนาย:** ข้อบ่งใช้อันดับ 2–10 (เช่น cauda equina syndrome, ADHD, ภาวะการใช้สารเสพติดบางชนิด, ความผิดปกติของการพัฒนา, กระเพาะปัสสาวะผิดปกติจากระบบประสาท) ส่วนใหญ่มีหลักฐานระดับ L4–L5 และแนะนำ Hold ทั้งหมดเช่นกัน
## ข้อจำกัดความรับผิดชอบ

เนื้อหานี้จัดทำขึ้นเพื่อการวิจัยเท่านั้น และไม่ถือเป็นคำแนะนำทางการแพทย์
จำเป็นต้องมีการตรวจสอบทางคลินิกก่อนนำไปใช้ทางคลินิก
